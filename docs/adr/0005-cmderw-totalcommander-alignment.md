# 0005 cmderw 对齐 Total Commander 的能力分期

- 状态：生效（A 批已落地，B–F 待实施）
- 日期：2026-11-10

## 背景

`cmderw` 已有双面板、独立历史、复制/移动/删除、新建/重命名、打包/解压、
搜索、哈希、属性、右键菜单与设置持久化，但离 Total Commander（下称 TC）的
日常文件管理闭环仍缺若干刚需动作。本 ADR 固化差距清单、批次顺序与关键取舍，
后续批次按此推进，不重新讨论已定口径。

能力对照（三档）：

| 档位 | TC 能力 | 现状 |
|---|---|---|
| 刚需 | 双面板、活动面板切换、交换、面板同步 | 双面板/切换/交换已有；同步未做 |
| 刚需 | 路径栏、前进/后退/上级、刷新 | 已有 |
| 刚需 | 多选、全选 | 已有 |
| 刚需 | 通配选择（Num+ / Num-）、反选 | 缺 |
| 刚需 | 复制/移动（目标可选）、删除到回收站 | 复制/移动/永久删除已有；目标固定为对面面板、无回收站 |
| 刚需 | 新建目录、单个重命名 | 已有 |

## 决策

### D1 删除默认进回收站

F8 移入系统回收站，Shift+F8 永久删除；两者都先确认，永久删除的确认文案明确
标注不可撤销。回收站不可用（平台不支持、跨卷失败）时只报错，**不回退为静默永久
删除**，由用户显式改走 Shift+F8。

### D2 回收站跨平台自实现，不引第三方依赖

- Windows：`SHFileOperationW`（`FOF_ALLOWUNDO`，ctypes 调用 shell32）。
- Linux：XDG Trash 规范，`${XDG_DATA_HOME:-~/.local/share}/Trash/{files,info}`，
  `info/*.trashinfo` 记录原路径与删除时间。
- macOS：移入 `~/.Trash`。
- 同目录同名冲突按 `name (2).ext` 生成唯一名，复用现有 `unique_path` 语义。

### D3 面板操作复用 `fnmatch`，选择与过滤语义分开

- 通配选择：文件名 glob，支持 `*` `?` 与 `;` 分隔多掩码，大小写不敏感。
- 快速过滤：当前目录列表的子串过滤（大小写不敏感），只影响显示，不改目录。
- 两者都是纯函数，输入文件名列表，输出名称集合，便于单测。

### D4 新增逻辑放 `_cmderw_ops.py`，窗口文件只留 Tk 装配

`cmderw.py` 已接近 2000 行；继续堆纯函数会失去可测边界。新增能力（回收站、
掩码匹配、过滤、目录统计）落在同域私有模块 `tools/system/_cmderw_ops.py`，
下划线前缀不参与工具发现（与 `_reshackw_core.py` 同例）。`cmderw.py` 导入并
经 `__all__` 重新导出，既有导入路径不变。

### D5 批次独立可回退

每批一个提交、只动本批文件；批次之间不共享未落地接口。

| 批次 | 内容 | 回退边界 |
|---|---|---|
| A | 回收站删除、复制/移动目标可编辑、通配选择/反选、快速过滤、目录大小 | `_cmderw_ops.py` + cmderw 面板/操作段 |
| B | 批量重命名（查找替换/正则/计数器，预览后执行）、搜索结果直接操作 | 重命名对话框 + 搜索对话框 |
| C | 标签页、书签、历史热列表 | `PanelState` 持久化结构（向后兼容） |
| D | 传输队列（串行、可取消、逐项状态） | worker/队列段 |
| E | 目录比较与同步（先预览计划再执行，删除需显式勾选） | 比较/同步对话框 |
| F | 内嵌快速查看、目录树、颜色规则、底部命令行 | 面板布局 |

### D6 持久化向后兼容

`~/.fcmd/ui/cmderw.json` 只增字段，读旧文件时缺失字段取默认值；标签页/书签
在 C 批引入时同样按此处理，不写迁移脚本。

## 落地状态

- A：已落地。F8 回收站 / Shift+F8 永久删除、F5/F6 目标可编辑、Num+/Num-/反选、
  Ctrl+S 快速过滤、Space 统计目录大小。
- B–F：待实施，按 D5 顺序推进。
