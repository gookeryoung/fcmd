# 0005 cmderw 对齐 Total Commander 的能力分期

- 状态：生效（A/B/C/D/E/F 批已落地）
- 日期：2026-11-10

## 背景

`cmderw` 已有双面板、独立历史、复制/移动/删除、新建/重命名、打包/解压、
搜索、哈希、属性、右键菜单与设置持久化，但离 Total Commander（下称 TC）的
日常文件管理闭环仍缺若干刚需动作。本 ADR 固化差距清单、批次顺序与关键取舍，
后续批次按此推进，不重新讨论已定口径。

能力对照（三档）：

| 档位 | TC 能力 | 现状 |
|---|---|---|
| 刚需 | 双面板、活动面板切换、交换、面板同步 | 双面板/切换/交换/比较/同步已有（E 批） |
| 刚需 | 路径栏、前进/后退/上级、刷新 | 已有 |
| 刚需 | 多选、全选 | 已有 |
| 刚需 | 通配选择（Num+ / Num-）、反选 | 已有（A 批） |
| 刚需 | 复制/移动（目标可选）、删除到回收站 | 已有（A 批） |
| 刚需 | 新建目录、单个重命名 | 已有 |
| 刚需 | 批量重命名（查找替换/正则/计数器） | 已有（B 批，不做正则） |
| 刚需 | 打包/解包 | 已有 |
| 刚需 | 按掩码搜索 | 已有（B 批，结果可直接操作） |
| 刚需 | 快速查看 | F3 弹窗已有；内嵌快速查看（Ctrl+Q）缺 |
| 刚需 | 快捷键、右键菜单、进度反馈 | 已有 |

| 锦上添花 | 颜色规则、自定义按钮栏、底部命令行、多步撤销 | 缺（仅目录/隐藏文件着色） |

## 决策

### D1 删除默认进回收站

F8 移入系统回收站，Shift+F8 永久删除；两者都先确认，永久删除的确认文案明确
标注不可撤销。回收站不可用（平台不支持、跨卷失败）时只报错，**不回退为静默永久
删除**，由用户显式改走 Shift+F8。

### D2 回收站跨平台自实现，不引第三方依赖

- Windows：`SHFileOperationW`（`FOF_ALLOWUNDO`，ctypes 调用 shell32）。
- Linux：XDG Trash 规范，`${XDG_DATA_HOME:-~/.local/share}/Trash/{files,info}`，
  `info/*.trashinfo` 记录原路径与删除时间。
- macOS：移入 `~/.Trash`。
- 同目录同名冲突按 `name (2).ext` 生成唯一名，复用现有 `unique_path` 语义。

### D3 面板操作复用 `fnmatch`，选择与过滤语义分开

- 通配选择：文件名 glob，支持 `*` `?` 与 `;` 分隔多掩码，大小写不敏感。
- 快速过滤：当前目录列表的子串过滤（大小写不敏感），只影响显示，不改目录。
- 两者都是纯函数，输入文件名列表，输出名称集合，便于单测。

### D4 新增逻辑放 `_cmderw_ops.py`，窗口文件只留 Tk 装配

`cmderw.py` 已接近 2000 行；继续堆纯函数会失去可测边界。新增能力（回收站、
掩码匹配、过滤、目录统计）落在同域私有模块 `tools/system/_cmderw_ops.py`，
下划线前缀不参与工具发现（与 `_reshackw_core.py` 同例）。`cmderw.py` 导入并
经 `__all__` 重新导出，既有导入路径不变。

### D5 批次独立可回退

每批一个提交、只动本批文件；批次之间不共享未落地接口。

| 批次 | 内容 | 回退边界 |
|---|---|---|
| A | 回收站删除、复制/移动目标可编辑、通配选择/反选、快速过滤、目录大小 | `_cmderw_ops.py` + cmderw 面板/操作段 |
| B | 批量重命名（查找替换/序号/大小写/扩展名，预览后执行）、搜索结果直接操作 | 重命名对话框 + 搜索对话框 |
| C | 标签页、书签、历史热列表 | `PanelState` 持久化结构（向后兼容） |
| D | 传输队列（串行、可取消、逐项状态） | worker/队列段 |
| E | E1 只读目录比较；E2 同步与删除（先预览计划再执行，删除需显式勾选） | 比较/同步对话框 |
| F | 内嵌快速查看、目录树、颜色规则、底部命令行 | 面板布局 |

### D6 持久化向后兼容

`~/.fcmd/ui/cmderw.json` 只增字段，读旧文件时缺失字段取默认值；标签页/书签
在 C 批引入时同样按此处理，不写迁移脚本。

### D7 批量重命名只做最小语法集，不做正则

- 查找替换是**字面**替换，`.` `*` 等按普通字符处理；不引入正则，避免语法与
  转义规则膨胀。
- 模板占位符仅 `{name}`（当前词干）、`{ext}`（不含点的扩展名）、`{n}`（按起始
  值 / 步长 / 位数补零）；字面花括号写 `{{` `}}`。模板为空时保留处理后的原名。
- 大小写四档：keep / lower / upper / title，只作用于词干，不动扩展名。
- 扩展名：留空不变，填 `-` 移除，其他值替换（自动去前导点）。
- 顺序：查找替换（作用于完整名称）→ 拆词干/扩展名 → 大小写 → 扩展名 → 模板。
- 冲突在预览阶段全部拦截并阻止执行：同批目标重名（大小写不敏感）、目标已存在
  （同源的大小写改名除外）、名称非法、模板无效。
- 执行后提供撤销，**只在本次运行内有效**（内存记录反向改名），界面明确提示
  关闭窗口后不可用。

### D8 搜索结果面板直接操作

搜索结果可打开所在目录、复制、移动、删除到回收站、加入活动面板选择。跨目录
“加入选择”时只选中第一个结果所在目录的条目，并在提示中逐目录列出被跳过项数。

### D9 标签页与书签的最小口径

- 每个面板独立维护标签列表与当前下标，互不共享；新建标签（Ctrl+T）沿用当前
  目录与排序，Ctrl+Tab / Ctrl+Shift+Tab 在本面板内循环切换。
- 关闭标签（Ctrl+W）仅剩一个时不关闭面板：保留该标签并在状态栏提示“至少保留
  一个标签页”，避免用户丢失当前路径；标签数量下限为 1。
- 持久化只增字段：`left_tabs` / `right_tabs` + `left_tab_index` / `right_tab_index`；
  旧配置只有 `left` / `right` 时按单标签读取，下标越界夹到末项。
- 书签是全局列表 `bookmarks`（添加时去重、保持顺序），但打开作用域是对话框
  打开时的活动面板；目录不存在时报错且不关闭对话框。两个面板都能各自打开
  自己的目录书签，不共享“当前标签”状态。
- 历史热列表（Alt+Down）用当前面板的历史栈倒序弹出，选中项只移动历史下标，
  不新增历史记录。

### D10 传输队列口径

- 串行执行：一次只跑一个任务，完成后再取队首；F5/F6 在后台任务进行中也可入队。
- 取消按项生效：进行中的任务收到取消后，当前文件传完即停，已完成项保留、未开始
  项标记取消；只清理“已开始但未完成”项的目标，未开始项与已完成项一律不碰；
  目标在本项开始前就存在且未走覆盖删除的视为用户文件，不清理。清理失败逐项
  报错，不静默忽略。
- 同队列目标冲突在入队时拦截并整批拒绝，提示写明冲突双方（任务描述 + 新任务
  动作/数量/目标）与具体目标路径；沿用现有同名冲突策略（覆盖/保留两者/跳过），
  不新增第三套语义。
- 失败项可单独或整批重试；目标路径已存在（多为上次半成品）时先确认覆盖，确认
  后才以覆盖策略重试。
- 队列状态、逐项进度、失败原因都在队列窗口可见；任务列表给汇总，明细表给每条
  来源/目标/状态/错误。
- 队列仅本次运行内有效：关窗时若仍有未完成任务，提示数量并要求确认；确认退出
  即停止，未开始的条目不会再启动，不偷偷留在后台继续传输。

### D11 目录比较口径（E1）

- 比较口径四档：仅文件名 / 按大小 / 按时间 / 按内容（SHA256）。默认按时间；
  「按时间」以大小为首筛，mtime 超差才记差异（2 秒容差，兼容 FAT 等粗粒度时间
  戳）；「按大小」只看大小；「仅文件名」只判两侧是否存在。非法模式回落按时间。
- 掩码过滤：包含掩码为空表示全收，排除掩码命中即丢弃；`;` 分隔多掩码、忽略大小
  写、只作用于文件名，目录仍继续遍历。「仅比较文件」勾选后结果不再包含目录条目。
- 类别四档：仅左侧 / 仅右侧 / 内容不同 / 相同；同层目录本身记为相同，子项差异
  逐条列出；递归、包含隐藏项（点前缀）都是开关，默认递归且跳过隐藏项。
- 全程只读：仅 `scandir` / `stat` / `readlink` / 只读 `open` 哈希，不在任一侧
  创建临时文件、不写任何目标目录。
- 不跟随符号链接：两侧同为链接时比较 `readlink` 文本，一侧链接一侧普通条目记
  「符号链接与普通条目」；相对路径只由目录项名拼接，不越出面板根目录。
- 读取失败（权限、竞态消失）逐条收进 `errors` 并在界面提示，不中断其余条目，
  也不静默吞掉。
- 快捷键 Ctrl+Shift+C；重复触发时前置已有比较窗口，不叠开新窗。

### D12 同步与删除口径（E2）

- 同步先出预演：复制/覆盖、待删除、策略跳过三组分别列出完整源/目标路径与总数，
  窗口内明确「执行前会重新校验目标端的大小与时间，与预演不一致的项将跳过并在结果中
  列出」，不在预演阶段预判后续变更。
- 方向三档：左→右 / 右→左 / 双向镜像。双向时单侧独有项复制到另一侧，不产生
  删除动作，两级删除勾选禁用；切回单向后恢复。复制按目标面板根分组入队。
- 冲突策略三档：总是覆盖（默认）/ 仅较新覆盖 / 跳过冲突。单向 + 仅较新时源端
  不比目标新（含容差内相等）就跳过；双向 + 仅较新按两侧 mtime 决定方向，容差内
  无法判定则跳过；双向 + 总是覆盖固定左→右。非法策略回落总是覆盖。
- 删除目标端多余项默认关闭；「同时删除目标端多余文件」勾选后，「允许删除多余目录
  及其内容」才可用（两级勾选，不做两个独立开关）。目录被跳过时其子项一并跳过。
- 复制/覆盖进入既有传输队列（D10 口径）；删除不进队列，按清单逐项移入回收站，
  任一项失败立即停止并汇报已完成与未执行数量；回收站不可用时整批中止，不降级为
  永久删除。
- 执行前对复制与删除项分别复核：源端消失、目标出现/消失、类型变化、大小或 mtime
  超出容差、符号链接，均记入跳过清单并显示原因，不静默略过。
- 预演清单首列可勾选（点击首列或按空格切换），支持全选 / 全不选 / 反选；只执行
  勾选项，未勾选数量写入结果；切换方向 / 冲突策略或重新预演会把勾选重置为全选。
- 执行结束弹结果窗口，列出复制入队（新建 / 覆盖）、删除完成、删除未执行、未勾选、
  执行前校验跳过与删除失败明细；明细超过 20 条时折叠并指向预演清单。
- 比较与同步都不跟随符号链接、不越出面板根目录；执行二次确认会明确
  「删除不可撤销（回收站可还原）」。

### D13 快速查看、目录树、颜色规则与命令行口径（F）

- 快速查看：内嵌活动面板底部，Ctrl+Q 开关；只读 `read_preview` 限读 256 KiB，
  覆盖文本 / 图片 / PE 或二进制（十六进制）三类；超限明确提示「已截断」；图片
  超过 32 MB 不在窗口内加载；目录、符号链接、缺失文件与 Tk 不支持的格式都给出
  明确提示，不留空白面板。
- 目录树：Ctrl+F8 显示 / 隐藏，单树跟随活动面板；懒加载（占位子节点 + 展开时读
  一层），只列子目录且不跟随符号链接；单击目录切换活动面板路径；面板切换目录、
  标签页或选中目录时反向定位；树只读，不做拖放。
- 颜色规则：只走「配置 → 颜色规则…」，不设快捷键；条件为掩码、最小 / 最大大小、
  类型（文件 / 目录 / 符号链接）、隐藏属性、最近 / 早于 N 天；列表顺序即优先级，
  靠下的规则覆盖靠上的同色属性，前景与背景独立合并；颜色仅接受 `#rrggbb`；
  持久化 `color_rules`，旧配置缺省为空列表。
- 命令行栏：默认隐藏，Ctrl+Enter 唤出并聚焦；`Enter` 执行、`Esc` 清空并返回，
  仅在命令行获得焦点时生效，不注册全局绑定；执行前校验工作目录为活动面板当前
  路径；含删除类命令（rm / del / rd / rmdir / Remove-Item / find -delete 等）先
  二次确认；在后台线程执行，结束后刷新面板并显示退出码与输出。

### D14 顶部下拉菜单栏（G）

- 分组固定为 文件 / 选中 / 视图 / 工具 / 命令 / 配置 / 帮助，不设「显示」「网络」；
  复制、移动、删除、属性、校验和只保留在「文件」，旧「编辑」「显示」菜单删除，
  避免同一动作出现两个入口。右键菜单是独立入口，不并入本口径。
- 菜单、快捷键、右键菜单与工具栏共用同一批 `CmderWindow` 方法，不另写动作实现。
- 启用/禁用由 `MenuFacts` → `menu_state()` 纯逻辑给出，Tk 层只在 `postcommand`
  调用 `_sync_menu_state()` 应用：无选中禁用单项与批处理动作、多选禁用单项、
  单标签禁用关闭标签、历史边界禁用后退/前进、忙碌禁用长任务、只读目录禁用写
  动作、面板未就绪禁用比较/同步、活动路径不存在禁用命令行栏。
- `_directory_writable()` 只作前置禁用依据；真正写失败仍由操作自身弹错，不吞
  异常，不让「文件只读」变成静默无反应。
- 勾选与单选变量以实际状态为准：菜单展开前把隐藏文件、目录树、快速查看、排序
  键与视图模式写回变量；Ctrl+H 修正为翻转变量后走 `_apply_hidden()`，不再只写回设置。
- 新增 `Alt+Left` 后退、`Alt+Right` 前进（与 TC 一致），其余键位不变。

### D15 TC 式视图模式与缩略图（H）

- 模式固定为 简要 / 详细 / 缩略图，存 `view_mode`，默认 `detailed`；简要只显示
  名称，详细列顺序固定 `name/ext/size/mtime/attr`，只允许拖宽度并存
  `column_widths`（未知列丢弃、整数夹到 40–2000、非法模式回落详细）。每面板每个
  标签独立记忆，新标签继承当前模式与列宽。
- 入口统一为 视图 →「视图模式」、右键菜单同名子菜单与 Ctrl+F1 / Ctrl+F2 /
  Ctrl+Shift+F1；不新增面板内按钮。菜单、快捷键、右键共用
  `CmderWindow.set_view_mode()`。
- 缩略图用 Canvas 网格虚拟化，只维护可视 ±1 行（每格 3 个 item）；2 个后台线程
  只读文件与解码（单文件限读 8 MiB），主线程每 60 ms 最多创建 2 个 PhotoImage；
  内存 LRU 256 张 / 32 MiB，不落盘；滚动 80 ms 防抖，移出视野且尚未开始的读取
  直接取消。
- 世代号 `ThumbnailRequestTracker` 覆盖刷新 / 切目录 / 切标签 / 切模式，旧世代
  结果丢弃；关窗 `shutdown(wait=True, cancel_futures=True)`，不留后台线程。
- Pillow 是项目常驻依赖（`pyproject.toml` 的 `dependencies`），PNG / GIF / PPM /
  JPEG / BMP / WebP / TIFF / ICO 统一交给 Pillow 解码并缩放到格子尺寸，不再探测
  可用性、不再回落到 Tk 原生解码；扩展名不在图片集合、文件超过 8 MiB 或解码失败
  时画类型徽标，状态栏提示「不是支持的图片格式」。
- 验收（Xvfb，5200 项目录）：加载 68.8 ms；简要 / 详细切换 3.7 / 8.4 ms；缩略图
  首帧 5.1 ms；20 次滚动单步最大 0.6 ms；画布常驻 108 个 item；进程 RSS 峰值增量
  38.4 MiB（含 5200 行 Treeview）；关窗后 `cmderw-thumb*` 线程为 0；名称列拖到

### D16 双面板同步浏览（I1）

- 开关放在 视图 →「同步浏览」（Ctrl+Shift+S），持久化 `sync_browse`，旧配置缺省关闭。
- 语义与 TC「同步切换目录」一致：按相对动作跟随——一侧进入子目录时对侧进入同名
  子目录，一侧返回上级时对侧也返回上级；路径栏直接跳转、书签、跨盘与历史跨步不
  跟随。
- 对侧没有同名子目录或已到根目录时保持不动并在状态栏提示，不创建目录、不弹错。
- 跟随会写入对侧历史，后退 / 前进在两侧各自独立；交换面板与启动初始化期间挂起
  跟随，避免递归与半初始化状态。

### D17 打开方式（I2）

- 文件菜单与右键菜单新增「打开方式…」，仅对单个文件启用；对话框可选择可执行程序
  （含「浏览…」），也可直接输入 PATH 上的命令名。
- 成功启动后把程序移到「最近使用」首位（去重、上限 8，持久化 `open_with`）；
  空值、带分隔符但不存在的程序、启动异常均弹错误提示且不记录。
- 纯逻辑在 `_cmderw_ops`：`normalize_open_with_list` / `remember_open_with` /
  `open_with_command`；启动用 `subprocess.Popen([program, path])`，跨平台可用。
