# 0005 cmderw 对齐 Total Commander 的能力分期

- 状态：生效（A/B/C/D/E 批已落地，F 待实施）
- 日期：2026-11-10

## 背景

`cmderw` 已有双面板、独立历史、复制/移动/删除、新建/重命名、打包/解压、
搜索、哈希、属性、右键菜单与设置持久化，但离 Total Commander（下称 TC）的
日常文件管理闭环仍缺若干刚需动作。本 ADR 固化差距清单、批次顺序与关键取舍，
后续批次按此推进，不重新讨论已定口径。

能力对照（三档）：

| 档位 | TC 能力 | 现状 |
|---|---|---|
| 刚需 | 双面板、活动面板切换、交换、面板同步 | 双面板/切换/交换/比较/同步已有（E 批） |
| 刚需 | 路径栏、前进/后退/上级、刷新 | 已有 |
| 刚需 | 多选、全选 | 已有 |
| 刚需 | 通配选择（Num+ / Num-）、反选 | 已有（A 批） |
| 刚需 | 复制/移动（目标可选）、删除到回收站 | 已有（A 批） |
| 刚需 | 新建目录、单个重命名 | 已有 |
| 刚需 | 批量重命名（查找替换/正则/计数器） | 已有（B 批，不做正则） |
| 刚需 | 打包/解包 | 已有 |

## 决策

### D1 删除默认进回收站

F8 移入系统回收站，Shift+F8 永久删除；两者都先确认，永久删除的确认文案明确
标注不可撤销。回收站不可用（平台不支持、跨卷失败）时只报错，**不回退为静默永久
删除**，由用户显式改走 Shift+F8。

### D2 回收站跨平台自实现，不引第三方依赖

- Windows：`SHFileOperationW`（`FOF_ALLOWUNDO`，ctypes 调用 shell32）。
- Linux：XDG Trash 规范，`${XDG_DATA_HOME:-~/.local/share}/Trash/{files,info}`，
  `info/*.trashinfo` 记录原路径与删除时间。
- macOS：移入 `~/.Trash`。
- 同目录同名冲突按 `name (2).ext` 生成唯一名，复用现有 `unique_path` 语义。

### D3 面板操作复用 `fnmatch`，选择与过滤语义分开

- 通配选择：文件名 glob，支持 `*` `?` 与 `;` 分隔多掩码，大小写不敏感。
- 快速过滤：当前目录列表的子串过滤（大小写不敏感），只影响显示，不改目录。
- 两者都是纯函数，输入文件名列表，输出名称集合，便于单测。

### D4 新增逻辑放 `_cmderw_ops.py`，窗口文件只留 Tk 装配

`cmderw.py` 已接近 2000 行；继续堆纯函数会失去可测边界。新增能力（回收站、
掩码匹配、过滤、目录统计）落在同域私有模块 `tools/system/_cmderw_ops.py`，
下划线前缀不参与工具发现（与 `_reshackw_core.py` 同例）。`cmderw.py` 导入并
经 `__all__` 重新导出，既有导入路径不变。

### D5 批次独立可回退

每批一个提交、只动本批文件；批次之间不共享未落地接口。

| 批次 | 内容 | 回退边界 |
|---|---|---|
| A | 回收站删除、复制/移动目标可编辑、通配选择/反选、快速过滤、目录大小 | `_cmderw_ops.py` + cmderw 面板/操作段 |
| B | 批量重命名（查找替换/序号/大小写/扩展名，预览后执行）、搜索结果直接操作 | 重命名对话框 + 搜索对话框 |
| C | 标签页、书签、历史热列表 | `PanelState` 持久化结构（向后兼容） |
| D | 传输队列（串行、可取消、逐项状态） | worker/队列段 |
| E | E1 只读目录比较；E2 同步与删除（先预览计划再执行，删除需显式勾选） | 比较/同步对话框 |
| F | 内嵌快速查看、目录树、颜色规则、底部命令行 | 面板布局 |

### D6 持久化向后兼容

`~/.fcmd/ui/cmderw.json` 只增字段，读旧文件时缺失字段取默认值；标签页/书签
在 C 批引入时同样按此处理，不写迁移脚本。

### D7 批量重命名只做最小语法集，不做正则

- 查找替换是**字面**替换，`.` `*` 等按普通字符处理；不引入正则，避免语法与
  转义规则膨胀。
- 模板占位符仅 `{name}`（当前词干）、`{ext}`（不含点的扩展名）、`{n}`（按起始
  值 / 步长 / 位数补零）；字面花括号写 `{{` `}}`。模板为空时保留处理后的原名。
- 大小写四档：keep / lower / upper / title，只作用于词干，不动扩展名。
- 扩展名：留空不变，填 `-` 移除，其他值替换（自动去前导点）。
- 顺序：查找替换（作用于完整名称）→ 拆词干/扩展名 → 大小写 → 扩展名 → 模板。
- 冲突在预览阶段全部拦截并阻止执行：同批目标重名（大小写不敏感）、目标已存在
  （同源的大小写改名除外）、名称非法、模板无效。
- 执行后提供撤销，**只在本次运行内有效**（内存记录反向改名），界面明确提示
  关闭窗口后不可用。

### D8 搜索结果面板直接操作

搜索结果可打开所在目录、复制、移动、删除到回收站、加入活动面板选择。跨目录
“加入选择”时只选中第一个结果所在目录的条目，并在提示中逐目录列出被跳过项数。

### D9 标签页与书签的最小口径

- 每个面板独立维护标签列表与当前下标，互不共享；新建标签（Ctrl+T）沿用当前
  目录与排序，Ctrl+Tab / Ctrl+Shift+Tab 在本面板内循环切换。
- 关闭标签（Ctrl+W）仅剩一个时不关闭面板：保留该标签并在状态栏提示“至少保留
  一个标签页”，避免用户丢失当前路径；标签数量下限为 1。
- 持久化只增字段：`left_tabs` / `right_tabs` + `left_tab_index` / `right_tab_index`；
  旧配置只有 `left` / `right` 时按单标签读取，下标越界夹到末项。
- 书签是全局列表 `bookmarks`（添加时去重、保持顺序），但打开作用域是对话框
  打开时的活动面板；目录不存在时报错且不关闭对话框。两个面板都能各自打开
  自己的目录书签，不共享“当前标签”状态。
- 历史热列表（Alt+Down）用当前面板的历史栈倒序弹出，选中项只移动历史下标，
  不新增历史记录。

### D10 传输队列口径

- 串行执行：一次只跑一个任务，完成后再取队首；F5/F6 在后台任务进行中也可入队。
- 取消按项生效：进行中的任务收到取消后，当前文件传完即停，已完成项保留、未开始
  项标记取消；只清理“已开始但未完成”项的目标，未开始项与已完成项一律不碰；
  目标在本项开始前就存在且未走覆盖删除的视为用户文件，不清理。清理失败逐项
  报错，不静默忽略。
- 同队列目标冲突在入队时拦截并整批拒绝，提示写明冲突双方（任务描述 + 新任务
  动作/数量/目标）与具体目标路径；沿用现有同名冲突策略（覆盖/保留两者/跳过），
  不新增第三套语义。
- 失败项可单独或整批重试；目标路径已存在（多为上次半成品）时先确认覆盖，确认
  后才以覆盖策略重试。
- 队列状态、逐项进度、失败原因都在队列窗口可见；任务列表给汇总，明细表给每条
  来源/目标/状态/错误。
- 队列仅本次运行内有效：关窗时若仍有未完成任务，提示数量并要求确认；确认退出
  即停止，未开始的条目不会再启动，不偷偷留在后台继续传输。

### D11 目录比较口径（E1）

- 差异判定默认「大小 + mtime，2 秒容差」（兼容 FAT 等粗粒度时间戳）；深度比较
  （逐文件 SHA256）作为显式可选项，不默认开启。
- 类别四档：仅左侧 / 仅右侧 / 内容不同 / 相同；同层目录本身记为相同，子项差异
  逐条列出；递归、包含隐藏项（点前缀）都是开关，默认递归且跳过隐藏项。
- 全程只读：仅 `scandir` / `stat` / `readlink` / 只读 `open` 哈希，不在任一侧
  创建临时文件、不写任何目标目录。
- 不跟随符号链接：两侧同为链接时比较 `readlink` 文本，一侧链接一侧普通条目记
  「符号链接与普通条目」；相对路径只由目录项名拼接，不越出面板根目录。
- 读取失败（权限、竞态消失）逐条收进 `errors` 并在界面提示，不中断其余条目，
  也不静默吞掉。
- 快捷键 Ctrl+Shift+C；重复触发时前置已有比较窗口，不叠开新窗。

### D12 同步与删除口径（E2）

- 同步先出预演：复制/覆盖、待删除、策略跳过三组分别列出完整源/目标路径与总数，
  窗口内明确「执行前会重新校验目标端的大小与时间，与预演不一致的项将跳过并在结果中
  列出」，不在预演阶段预判后续变更。
- 方向左→右 / 右→左可选；左侧或右侧仅有的条目按方向决定复制还是删除。
- 删除目标端多余项默认关闭；「同时删除目标端多余文件」勾选后，「允许删除多余目录
  及其内容」才可用（两级勾选，不做两个独立开关）。目录被跳过时其子项一并跳过。
- 复制/覆盖进入既有传输队列（D10 口径）；删除不进队列，按清单逐项移入回收站，
  任一项失败立即停止并汇报已完成与未执行数量；回收站不可用时整批中止，不降级为
  永久删除。
- 执行前对复制与删除项分别复核：源端消失、目标出现/消失、类型变化、大小或 mtime
  超出容差、符号链接，均记入跳过清单并显示原因，不静默略过。
- 比较与同步都不跟随符号链接、不越出面板根目录；执行二次确认会明确
  「删除不可撤销（回收站可还原）」。

## 落地状态

- A：已落地。F8 回收站 / Shift+F8 永久删除、F5/F6 目标可编辑、Num+/Num-/反选、
  Ctrl+S 快速过滤、Space 统计目录大小。
- B：已落地。Ctrl+M 批量重命名（预览、冲突拦截、执行、本次运行内撤销）、
  搜索结果面板直接复制/移动/删除/打开所在目录/加入选择。
- C：已落地。每面板多标签（Ctrl+T 新建 / Ctrl+W 关闭 / Ctrl+Tab 切换，至少保留
  一个标签）、Ctrl+D 书签（持久化 `bookmarks`，打开作用于当前活动面板）、
  Alt+Down 历史热列表；标签与书签两个面板各自独立。
- D：已落地。复制/移动进入串行传输队列；入队校验同队列目标冲突并拒绝；逐项
  状态与失败原因在队列窗口可见；运行中取消按项生效并只清理该项半成品；失败项
  可单独或整批重试；关窗对未完成任务要求确认。
- E1：已落地。Ctrl+Shift+C 只读目录比较：默认大小 + 2 秒 mtime 容差，可开深度
  哈希；递归 / 隐藏项开关；结果按仅左侧 / 仅右侧 / 内容不同 / 相同分类过滤，显示
  相对路径、两侧大小与说明，读取错误单独提示。
- E2：已落地。比较窗口「同步…」与工具菜单「目录同步…」进入预演：方向切换、
  复制/覆盖/待删除/跳过明细与总数、两级删除勾选；执行前复核大小与 mtime，变更项
  单独列出；复制入传输队列，删除走回收站逐项执行、失败即停并汇报。
- F：待实施，按 D5 顺序推进。

## 交接

- 下一步是 F 批（快速查看内嵌 / 目录树 / 颜色规则 / 命令行栏）。涉及新按键映射
  时先把映射表交用户确认，避免与系统或现有快捷键冲突后再实现。
- E 批的比较与同步都不跟随符号链接、不越出面板根目录；目标端执行前重新校验
  mtime/大小，被改过的项跳过并在结果里单独标记。
- 同步复制/覆盖走既有传输队列（D10 口径），删除单独逐项执行、优先回收站、
  失败即停并汇报；后续改动不要把这些动作重新塞回队列。
- 新增纯函数优先放 `_cmderw_ops.py`；Tk 类仍留在 `cmderw.py` 并标
  `# pragma: no cover`，与既有窗口一致。
- 回收站删除的测试在 Linux 上走 XDG 分支用临时 `XDG_DATA_HOME`，Windows 分支
  只测参数拼装，不真删文件。
- 设置 JSON 的 `left_tabs` / `right_tabs` / `bookmarks` 是 C 批新增字段；改结构时
  保持“只增字段 + 缺失取默认”，不写迁移脚本。
- 传输队列模型（`TransferQueue` / `QueueTask` / `QueueItem`）在 `_cmderw_ops.py`，
  Tk 只做调度；新增队列字段同样只增不改。
- 搜索结果的“加入选择”提示按目录计数，后续若支持正则需单开 ADR 讨论转义与
  捕获组引用，不在 B 批口径内追加。
