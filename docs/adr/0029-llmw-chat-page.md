# 0029 locllmw 对话页：整合 llmchatw

- 状态：已落地
- 日期：2026-11-14
- 相关文档：[ADR 0025](0025-sidebar-page-navigation.md)、[ADR 0027](0027-llmw-rename.md)

## 背景

`llmchatw` 是独立的 Tk 聊天窗口：服务选择、自定义 OpenAI 兼容地址、流式回复、
思考过程展示、图片附件与采样参数都已成熟。`locllmw` 的「对话」页从
[ADR 0027](0027-llmw-rename.md) 起一直是占位，用户需要在两个窗口之间来回切换：
在 `locllmw` 启动服务，再到 `llmchatw` 选服务对话。两边都读取同一份
`llmenv` 状态，却维护两套窗口设置（`llmw.json` / `llmchatw.json`）。

## 决策

### 1. 对话能力迁入 `locllmw` 对话页

- 新增 `_llmw_chat.py` 的 `_LocllmWindowChat` mixin，从原 `ChatWindow`
  迁移连接表单、生成参数、流式对话、图片附件与停止 / 清空逻辑；
- 页面控件由 `SidebarNav` 的 chat 页承载，字符串状态与历史保存在控件内，
  **切页不丢失**，并持久化到 `llmw.json`（见下方「对话历史落盘」）；
- 新增 `_on_page_changed("chat")`：每次进入对话页刷新 `llmenv` 服务列表，
  启动服务后无需手动点刷新（刷新按钮仍保留）；
- 关窗时 `_close_chat()` 取消当前生成并等待后台线程收尾，避免遗留请求。

### 2. 命名隔离

对话页的状态与控件全部使用 `_chat_*` 前缀，避免与宿主冲突：

| 原 `ChatWindow` | 迁移后 |
|---|---|
| `_thread` / `_messages` / `_running` | `_chat_thread` / `_chat_messages` / `_chat_running` |
| `_status_var` / `_service_var` / `_model_var` | `_chat_status_var` / `_chat_service_var` / `_chat_model_var` |
| `_send` / `_stop` / `_clear` | `_chat_send` / `_chat_stop` / `_chat_clear` |
| `_chat`（Text） | `_chat_text` |

`locllmw` 自身已有启动 / 停止任务线程与状态栏，重名会导致停止按钮操作错对象，
因此不保留原名。

### 3. 移除独立工具 `llmchatw`

- 删除 `src/fcmd/apps/llm/llmchatw.py`；
- 删除 `pyproject.toml` 入口、工具注册、`_schema` GUI 工具集合与静态清单条目；
- 设置不再写 `~/.fcmd/ui/llmchatw.json`，窗口几何统一由 `llmw.json` 管理；
- CLI `llmchat` 保留，作为脚本化对话入口；交互式对话统一进 `locllmw`。

### 4. 布局适配

页面参考 DeepSeek / DSH 一类的对话产品，进一步精简为**左侧对话列表 + 右侧
正文阅读区 + 底部对话框**，不再保留顶部连接条或折叠分区：

- 对话状态统一显示在窗口底部状态栏（不再占用对话区顶部一行）：未开始 /
  已选择服务 / 生成中 / 未登记服务等；状态按页面归属，切到其它页再切回时恢复。
  未登记服务这类空态提示因此直接出现在底部，不与正文争夺视线；
- 正文不再包卡片边框，直接铺在页面底色上；
- 底部对话框是独立大圆角卡片（`#ChatComposer`，16px），内含 3–4 行无边框输入框
  与 34px 高工具行，`Ctrl+Enter` 发送。工具行只放齿轮图标按钮（模型与生成配置）、
  「对话 / 画图」胶囊与发送按钮；**不再放模型胶囊**——模型与服务是同一件事，
  全部收进 ⚙ 配置窗口，减少一个与运行页重复的入口。
  齿轮右侧是「对话 / 画图」两枚 30px 高全圆角胶囊开关（`ToggleChip`，参考元宝
  输入区的模式开关）：图标 + 文字，未选中为浅灰底、选中为淡强调色底 + 强调色
  文字，互斥切换发送内容（对话即普通问答、画图走 sd.cpp 出图），图标色调随
  选中状态在 muted / accent 间同步；旧的「画图」勾选框不再保留。胶囊的图标与
  文字由控件自绘（QSS 只负责底色 / 圆角 / 悬停与选中态）：左右留白固定相等、
  内容整体居中，且 QSS `padding` 必须归零——通用 `QToolButton` 的上下内边距会
  把 QSS `min-height` 的内容高撑成 38px，胶囊变高、不再是正胶囊。
  左侧对话列表底部是一条无边框透明操作条（`ChatSidebarActions`）：
  复制 / 删除 / 清空三个 30px 透明图标按钮等宽铺满，不包描边容器，避免喧宾夺主。
  发送 / 停止合并成同一个 34×34 无边框图标按钮（与齿轮同为透明底，hover 显淡
  色底）：空闲为 accent 发送图标，生成中切换为 danger 停止图标与提示，不再
  单独放停止 / 导出文字按钮；
- 模型 / 服务地址 / API Key / 系统提示 / 输出上限 / temperature 全部收进
  **独立的「模型与生成配置」窗口**（非模态，点齿轮打开），不占用对话页与对话框
  区域；服务下拉、刷新与状态胶囊也在该窗口内，修改即时生效。
- 配置窗口按接入方式分两态，避免与运行页重复：
  - 默认「已登记服务」：地址 / 模型名（alias）/ API Key 全部由运行页启动参数写入
    的服务状态回填，窗口里只读展示一行摘要（`base_url` + alias + 来源说明），
    不展开输入框——它们改的是客户端连接，手填只会造成「服务在 A 口、对话连 B 口」；
  - 勾选「自定义接入（外部 OpenAI 兼容服务）」才展开模型名 / 服务地址 / API Key
    三个输入框；勾选时服务下拉切到「自定义」，取消时回到第一个已登记服务（没有
    已登记服务时保持自定义，不能把地址输入框藏掉）。
  选择已登记服务不向正文插入切换提示，只在底部状态栏说明。
- 配置窗口以「贴合内容」为默认：初始 640×430，不再强制 520px 最小滚动高度，
  也不在末尾加 stretch；「画图（采样 / 输出）」收进 `Collapsible` 默认收起，
  只在需要调尺寸 / 步数 / 输出目录时展开（展开时窗口长高到 660，屏幕放不下才滚动），
  避免打开配置窗口就占掉半个屏幕、底部留一大片空白。
- 思考内容按一轮聚合成单个灰色斜体区块，不会为每个流式分片重复 `[思考]` 前缀。
- 左侧历史栏顶部「＋ 新对话」复用运行页 `RunPrimary` 尺寸（比常规按钮略高、
  更宽的左右内边距），与「启动服务」主操作按钮同权重。

页面左侧对话历史栏与右侧对话区之间用可拖动 splitter：默认宽度即最小宽度
120px（旧版默认 160 / 200 / 240 迁移到 120，避免升级后仍然过宽），可向右
展开到 480px；长对话标题右侧省略（tooltip 显示全名）且不出现
横向滚动条，列表不会把侧栏撑宽；28×28 收起 / 展开键挂在**主窗口页标题行**
（`header_widgets()` 注册到 `QtMainWindow.header_actions`，与「对话」标题同一行），
不再在正文上方单独占一行——离开对话页时隐藏且不占位。收起后侧栏宽度归零、
正文占满整页，标题行的小箭头仍作为展开入口。当前宽度与收起
状态分别写回 `llmw.json` 的 `chat_sidebar_width` / `chat_sidebar_collapsed`；
不再写死固定宽度。

历史栏顶部只有「＋ 新对话」，下方直接是本次窗口内的所有
对话（行高 / hover / 选中态与其它列表一致），不再单独占一行标题 / 条数；点击可
切回并恢复对应记录，生成过程中暂时禁用切换与新建。
历史栏底部提供**复制 / 删除 / 清空全部**三个 34×34 图标键（参考 DSH）：
复制把当前对话正文写入剪贴板并提示；删除只移除当前选中对话，删掉最后一个时
回到空白新对话；清空全部先弹确认，完成后同样回到空白新对话。生成过程中删除 /
清空禁用并提示先停止，复制保持可用。

**对话历史落盘**：`llmw.json` 新增 `chat_history`（最近 20 个对话）与
`chat_active`（选中下标）。每个对话保存标题、已渲染块与
`ChatSession` 的 endpoint / system / 采样参数 / messages；重启后恢复
标题列表、正文、选中项与多轮上下文，切回某个对话时同时把连接参数与
采样参数回填到表单，保证可以直接继续追问。新建 / 删除 / 清空 / 生成完成 /
生成失败 / 关闭窗口时各落盘一次；超出 20 条只保留最近记录。

连接参数由服务下拉框自动回填；服务列表刷新按钮放回顶部，不再占用单独一行。

### 5. 服务空态与不可用区分

- 服务下拉框显示「名称（运行中）」或「名称（已退出）」；选中项通过
  显示文案 → 服务名映射还原，自定义地址仍为「自定义」。
- 窗口底部状态栏按原因给引导，不再统一显示「不可用」：
  - 没有登记服务 → 「去『运行』页启动，或点『刷新服务列表』」；
  - 服务进程已退出 → 指明服务名并提示重新启动或刷新；
  - 手动选择自定义 → 「可直接填写下方地址接入其它 OpenAI 兼容服务」。
- 全部服务都不可用时仍自动选中第一个，让用户先看到具体退出原因，而不是只看到
  「未选择」。

## 验证

- `tests/apps/llm/test_cli_llmchat.py`：注册表断言 `llmchatw` 已移除；
  服务刷新 / 自定义地址 / 不可用服务提示改为针对 `_LocllmWindowChat` 的纯逻辑测试。
- 真实 Tk 冒烟：`locllmw` 创建窗口后切到「对话」页，服务下拉框填充、发送按钮
  与图片按钮可用、切页后状态保留、关闭窗口不留下线程。
- Qt 冒烟：切到对话页断言侧栏收起键与页面标题同一行、正文不再被额外动作行占位，
  收起 / 展开状态与设置落盘；离开对话页时收起键隐藏。
- 模式胶囊：`tests/apps/llm/test_llmw_qt_smoke.py` 断言「对话 / 画图」互斥切换、
  占位提示与 `paint.enabled` 落盘；`tests/gui/test_qt_widgets.py` 验证胶囊图标
  色调切换、上屏后高度仍为 30px、内容宽度按左右等宽留白计算、内容色随主题
  token；`tests/gui/test_qt_theme.py` 固定全圆角、padding 归零与强调色选中态样式。
- 全量测试与 `make check-fast` 通过。

## 交接

- 对话历史已落盘到 `LlmSettings.chat_history` / `chat_active`（最多 20 条），
  不要恢复独立窗口；新增字段需同步 `_llmw_winsettings` 的读写与容错。
- 消息只保存 `role / content`，图片附件不落盘（体积与隐私考虑）；已渲染块保留
  完整文本，用于重启后的正文展示。
- 复制键使用 `transcript.toPlainText()`（与界面展示一致）；不再提供 Markdown
  导出按钮，避免和「复制」重复占工具行。

## 交接

- 左侧对话历史使用公共 `fcmd.gui.widgets.SidebarList`（`SidebarEntry`）：
  圆角选中底、标题省略、悬停 / 选中自绘，不再依赖 `QListWidget#ChatHistory` 的
  整行方块与左侧强调条；需要分组 / 副标题 / 右侧摘要时可继续用同一组件。
