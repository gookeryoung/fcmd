# 0007 cmderw 压缩包内浏览

- 状态：生效（J 批）
- 日期：2026-11-11

## 背景

Total Commander 允许把压缩包当目录浏览（Enter / Ctrl+PageDown 进入，内部只读），并可直接
从包内复制 / 解压选中成员。cmderw 目前只有「解压整个压缩包」，无法先看结构再决定解压
哪些内容。

## 决策

1. 支持范围
   - 只读浏览 `zip`、`tar`（含 `tar.gz` / `tgz` / `tar.bz2` / `tar.xz`）与单文件
     `gz` / `bz2` / `xz`，全部使用标准库。
   - `7z` / `rar` 不进入浏览，提示改用现有「解压…」（依赖外部工具）；不支持的文件格式
     直接报错，不猜测。
2. 进入与退出
   - Enter / 双击受支持的归档文件进入；右键菜单与文件菜单提供「进入压缩包」。
   - 包根按 Backspace / 上级目录退出到归档所在磁盘目录；切换到其他目录（路径栏、后退 /
     前进、标签切换、同步浏览）自动退出浏览。
3. 浏览模型
   - 面板进入只读虚拟目录：路径栏显示 `归档路径/内部目录`，但 `PanelState.path` 保持归档
     所在的磁盘目录，历史与标签不受影响，退出后回到进入前的目录。
   - 列表只显示当前层级的直接子项（目录 + 文件），带大小与时间；排序、快速过滤、
     键盘选择可用；状态栏标注「压缩包 · 只读」。
   - 缩略图视图在包内只画类型徽标，不解码包内图片；可切回简要 / 详细视图。
   - 过滤条件、排序方向与列宽沿用当前标签设置，不写入 `PanelState.path`。
4. 查看与打开
   - F3 / 快速查看 / Enter 打开包内文件时按需解压到 `fcmd-arcview-` 临时目录后复用现有
     查看器与系统默认程序；单文件上限沿用快速查看的 32 MiB 限制，超限提示。
   - 退出浏览或关闭窗口时删除临时目录。
5. 解压与复制
   - F5 / 「解压选中」把选中成员（含子目录）解压到对面面板或用户指定目录，保留包内相对
     结构；F6 在包内同样按导出处理并提示只读。
   - 目标已存在同名条目时统一确认是否覆盖，取消则不解压任何文件。
   - 拒绝绝对路径、`..` 穿越与符号链接目标越界；加密成员给出明确提示并跳过。
6. 只读约束
   - 包内禁用：新建目录 / 文件、重命名、批量重命名、删除、移动、打包、属性、打开方式。
   - 允许：查看、打开（临时解压）、复制 / 解压、快速过滤、排序、切换视图与面板。

## 落地状态

- J1：浏览与导航（进入 / 退出、目录下钻、排序过滤、状态栏只读标识）。
- J2：按需解压查看 / 打开与临时目录清理。
- J3：选中成员解压 / 复制（保留相对结构、路径穿越校验、冲突处理）。
- J4：包内只读菜单禁用与错误提示。

## 交接

- 列表读取集中在 `read_archive_members`，解压集中在 `extract_archive_members`；新增格式时
  只扩展这两个函数与格式判定，不在 Tk 层散落分支。
- 归档视图是面板运行期状态（`FilePanel.archive` / `archive_prefix`），不进入设置文件；
  如需跨会话保留，另开 ADR 设计虚拟路径持久化。
- 7z / rar 若将来需要浏览，先评估外部工具输出解析的稳定性，再扩展本 ADR。
