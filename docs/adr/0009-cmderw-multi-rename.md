# 0009 cmderw 多重命名工具（TC 对齐）

- 状态：生效（M 批）
- 日期：2026-11-11
- 关联：0005（cmderw 与 Total Commander 对齐）

## 背景

`cmderw` 现有批量重命名只支持「查找替换 + `{name}/{ext}/{n}` 模板 + 大小写」，
与 Total Commander 的多重命名工具差距明显：没有名称 / 扩展名分离的掩码、没有名称
片段与日期时间占位符、没有正则查找替换、没有可勾选的预览、没有预设。用户需要把
现有 `Ctrl+M` 升级为完整的 TC 式多重命名工具。

## 决策

### 1. 掩码表达式

- 名称掩码与扩展名掩码分开：名称掩码默认 `[N]`，扩展名掩码默认 `[E]`；
  扩展名掩码留空表示保留原扩展名，填 `-` 表示移除扩展名。
- 占位符：
  - `[N]`：原名称（不含扩展名；目录为整个名称）。
  - `[N#-#]`：原名称的 1 起始闭区间片段，越界按实际长度截断，起点大于终点报错。
  - `[E]`：原扩展名（不含点）。
  - `[C]`：计数器，按位数补零。
  - `[Y]` `[M]` `[D]` `[h]` `[m]` `[s]`：条目修改时间的年（4 位）/月/日/时/分/秒
    （均 2 位补零）。
  - `[[` 输出字面 `[`；其余 `[` 必须能匹配到已知占位符。
- 非法占位符、未闭合 `[`、空区间、非法数字范围一律抛出 `MaskError`（带占位符原文
  与位置），不静默丢弃；Tk 层把错误显示在预览状态栏并禁用执行。

### 2. 求值顺序

1. 拆分原名与扩展名（目录无扩展名）。
2. 查找替换：普通 / 正则两种模式，可选区分大小写、仅扩展到扩展名；正则非法时
   抛错。普通模式按字面替换，正则模式支持 `\1` 反向引用。
3. 展开名称掩码与扩展名掩码，`[N]` / `[E]` 使用替换后的值。
4. 大小写转换只作用于展开后的名称部分（不动扩展名），模式：保持 / 小写 / 大写 /
   每词首字母大写 / 仅首字母大写。
5. 计数器按排序后的位置取值：名称（大小写不敏感）/ 创建时间 / 修改时间升序。

### 3. 预览与校验

- 行状态：`ok`（可执行）、`unchanged`（名称未变化）、`invalid`（空名、非法字符、
  路径分隔符、超过 255 字符、非法掩码）、`conflict`（同批重名、目标已存在）。
- 预览表列出「旧名 → 新名」与状态说明；只有 `ok` 行可勾选，默认全选，支持全选 /
  全不选。执行仅作用于勾选且仍为 `ok` 的行；预览后有文件系统变化时执行阶段再次
  校验，冲突项跳过并报告。
- 执行复用 `apply_rename_plan` / `undo_rename`，保留本次运行内撤销。

### 4. 预设

- 预设 = 名称（唯一）+ 全部规则字段，持久化到 `CmderSettings.rename_presets`。
- 上限 50 条；保存同名覆盖；加载非法 / 缺失字段回落默认值，非法条目丢弃；名称空白
  或重复时保留首个。
- 预设只保存规则，不保存选择集与勾选状态。

### 5. 入口与选择集

- 继续使用「文件 → 批量重命名…（Ctrl+M）」与右键入口，菜单键名保持
  `bulk_rename`（读写守卫与菜单状态沿用既有口径）。
- 支持分支视图：每条输入使用自身绝对路径参与改名，显示旧名时使用相对路径标签；
  执行后刷新面板并按新名称恢复选择（分支视图按相对标签恢复）。
- 压缩包内为只读浏览，沿用现有守卫直接拒绝。

## 落地状态

- M1：已落地。纯逻辑模块 `_rename.py`（掩码、查找替换、大小写、计数器、
  预览、预设）与单测。
- M2：已落地。Tk 多重命名工具对话框（预设、勾选预览、执行 / 撤销）并接入 `Ctrl+M`。
- M3：已落地。设置持久化 `rename_presets`、README / 0005 状态回填、门禁与镜像同步。

## 交接

- 纯逻辑全部在 `_rename.py`，Tk 层只做变量绑定、预览渲染与执行调度。
- 旧的 `BulkRenameOptions` / `build_new_name` / `plan_bulk_rename` 随本次升级移除，
  执行与撤销继续复用 `RenamePlan` / `apply_rename_plan` / `undo_rename`。
- 预设持久化字段为设置 JSON 的 `rename_presets`（上限 50）：旧配置缺失时回落空列表，
  非法条目 / 非法选项值丢弃并回落默认，不做迁移脚本。
- 若后续需要参数级命名模板、正则捕获组进入掩码或预设导入导出，另开 ADR。
