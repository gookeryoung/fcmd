# 0010 cmderw 用户命令与外部工具入口

- 状态：生效（N1–N2）
- 日期：2026-11-11
- 关联：0005（cmderw 与 Total Commander 对齐）

## 背景

Total Commander 允许把常用的外部命令挂到开始菜单、按钮栏与右键菜单，并用
`%P` / `%T` / `%N` / `%S` 一类占位符把当前目录与选中项传给命令。cmderw 目前只有
底部命令行栏，外部命令每次都要手工输入完整路径与文件名，无法复用。

本 ADR 固化用户命令的模型、占位符口径、入口与持久化。

## 决策

### 1. 命令模型

- 一条用户命令 = 名称 + 命令模板 + 参数模板 + 三个入口开关（菜单 / 工具栏 / 右键）。
- 名称与命令模板都必填；名称重复时保留首个；上限 50 条。
- 执行时把「命令模板 + 空格 + 参数模板」展开后交给平台 shell（与命令行栏同一路径）。

### 2. 占位符

- `%P`：活动面板当前目录绝对路径。
- `%T`：对面面板当前目录绝对路径。
- `%N`：活动面板首个选中项名称；无选中时展开为空串。
- `%S`：全部选中项名称；空格分隔，每项双引号包裹，内部 `"` 转义为 `\"`。
- `%L`：全部选中项完整路径，分隔与引号规则同 `%S`。
- `%%`：输出字面 `%`。
- 其它 `%X` 与结尾孤立 `%` 抛 `PlaceholderError`（带原文与位置），不静默丢弃；
  Tk 层把错误显示出来并放弃本次执行。

### 3. 执行

- 工作目录固定为活动面板当前目录；目录不存在时拒绝执行并提示。
- 复用命令行栏的后台执行与输出窗口；命令含删除类操作时沿用
  `destructive_command` 二次确认。
- 执行结束后刷新两侧面板并保留当前选择。
- 压缩包只读浏览状态下仍允许执行（命令只读自身负责），占位符取归档所在磁盘目录。

### 4. 入口与持久化

- 「配置 → 用户命令…」打开管理对话框：新增 / 编辑 / 删除 / 上移 / 下移 / 运行。
- 「命令 → 用户命令」动态子菜单、工具栏按钮、右键子菜单分别展示勾选了对应入口
  的命令；命令变更后立即重建三处入口，无需重启。
- 持久化字段 `user_commands`。旧配置缺失回落空列表；非字典条目、空名称、空命令、
  重名条目丢弃；三个开关字段非布尔时回落 `true`。

## 落地状态

- N1：已落地。纯逻辑模块 `_commands.py`（命令模型、占位符展开、序列化容错）
  与单测；设置字段 `user_commands` 读写。
- N2：已落地。管理对话框、菜单 / 工具栏 / 右键三处入口与执行调度。

## 交接

- 占位符与命令模型全部在 `_commands.py`，Tk 层只做上下文收集、入口重建与执行。
- 新增占位符时同时更新 `PLACEHOLDERS`、本 ADR 与 `TestUserCommands`，并保持
  「未知占位符报错而非空串」的口径。
- 用户命令与命令行栏共享 `_run_shell` / `_command_finished`，不要再写第二套执行器。
