# 0012 cmderw P3 文件工具：归档写入、分卷、重复文件、包内搜索与标签交互

- 状态：生效（P3）
- 日期：2026-11-11
- 关联：0005（cmderw 与 Total Commander 对齐）、0007（压缩包内浏览与写入）、0011（P2 增强）

## 背景

P2（N3–N7）收尾后，cmderw 在「包内改内容、大文件分卷、清理重复文件、包内找内容、
标签与过滤」上仍缺入口。本 ADR 固化 P3 的口径，纯逻辑继续与 Tk 层分离。

## 决策

### P3-1 归档内写入

- 可写格式与浏览一致：zip 家族与 tar 家族（含单文件 gz / bz2 / xz 的解压入口不变）。
  7z / rar 等仍只读，只能走「解压…」。
- 包内新增、删除、改名都按成员名前缀处理：目录项整棵生效，改名保留子成员。
- 压缩级别 0–9，默认 6；zip 级别 0 用 `ZIP_STORED`，tar.gz / tar.bz2 / tar.xz
  分别映射到 gzip / bz2 / lzma（bz2 最小 1）。
- 密码只对 zip 生效：有密码时用可选依赖 `pyzipper` 写 AES-256，无密码时用标准
  `zipfile`；tar 家族与只读格式传入密码直接报错，不静默忽略。
- 原子写入：同目录临时文件（保留 `.tar.gz` 等完整后缀）→ 重新打开校验成员名与
  可读性 → `Path.replace` 覆盖原包；任一步失败删除临时文件，原包保持不变。
- 冲突与确认复用现有入口：新增目标已存在抛 `FileExistsError`，UI 走覆盖确认；
  删除 / 改名沿用包内只读时已有的确认框。

### P3-2 文件分割与合并

- 分割支持按大小（`parse_size` 的 K/M/G 写法）或按份数二选一，份数不能超过字节数。
- 分卷名 `{主名}.{序号}`，序号宽度取 `max(3, len(str(份数)))`，并生成
  `{主名}.sha256` 校验文件（内容为摘要与总字节数）。
- 合并从任一分卷发现同组文件，按序号升序拼接；编号缺口、混组或非分卷文件拒绝执行。
- 有校验文件时核对 SHA-256 与总大小，不一致删除输出并报错；`verify=False` 只跳过
  校验文件的比对，不跳过顺序检查。
- 分卷先写临时文件再改名；失败清理本次已建分卷与校验文件，不留半成品。

### P3-3 重复文件查找

- 先按文件大小分桶，仅对同大小桶计算哈希（默认 SHA-256），复用
  `hashbase.iter_directory_files` 与 `compute_file_hash`。
- 重叠根目录按解析后的真实路径去重，避免同一文件扫两次；空文件默认不参与。
- 结果按浪费空间降序；可批量删除到回收站 / 永久删除，或移动到目标目录；移动时
  同名冲突自动改用 `stem (2).suffix`，不覆盖既有文件。

### P3-4 归档内搜索

- 成员名用 glob（`fnmatch`，可切换大小写），内容用复用 `fileops` 的正则编译入口，
  支持大小写与整词；结果给出成员名、行号与命中文本。
- 内容读取逐成员流式进行：先读 64 KiB 探测编码，再按增量解码器逐行匹配；含 NUL
  的成员按二进制跳过，不整包解压到临时目录。
- 加密成员、超过 32 MiB 的成员与超过行数上限的成员计入「跳过」；命中数达到上限
  标记截断，避免大包拖死 UI。

### P3-5 标签、选择与过滤器

- 标签状态增加自定义名、锁定与选择记忆：锁定标签拒绝 Ctrl+W，「关闭其他」保留
  当前与锁定标签；重命名留空恢复目录名。
- 切换标签与退出时保存可见选择，重启后按名称恢复，已消失的条目自动忽略。
- 「定义过滤器」支持包含 / 排除掩码（glob，分号分隔多个），与快速过滤叠加且只
  影响列表显示；定义写入 `CmderSettings.filter_definition`，启动时恢复。

- P3-2：已落地。`_cmderw_split.py`、文件菜单「分割文件…」「合并分卷…」。
- P3-3：已落地。`_cmderw_dupes.py`、「查找重复文件…」结果窗口。

## 交接

- 归档写入集中在 `_cmderw_archwrite`，新增可写格式时只扩展 `_zip_writer` /
  `_tar_writer` 与 `archive_editable`，不要绕过临时文件 + 校验 + 替换。
- 分卷编号宽度由总份数决定；手工改名分卷会导致合并拒绝，需保持同组同宽。
- 重复文件只对同大小文件哈希；新增算法时同步更新设置口径与结果说明。
- 包内搜索不返回二进制成员内容；调整上限时同时看内存与 UI 响应。
- 标签锁定 / 选择 / 过滤器字段只向 `cmderw.json` 增字段，旧配置缺失字段走默认值。
