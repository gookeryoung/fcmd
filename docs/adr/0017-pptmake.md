# 0017 pptmake：PPT 模板设计器

## 背景

仓库已有大量文件、文档与开发工具，但缺少「排版 -> 模板 -> 演示文稿」这条链路。
需求是新增 `pptmake` 应用，提供布局设计、风格设计与精美 UI 生成能力，用于生成
PPT 模板，并支持模板导入导出。

约束：

- 纯逻辑与 Qt 分离，纯逻辑可单测，GUI 不纳入 CI 覆盖率；
- 不引入重量级 GUI 框架，沿用 `fcmd.gui` 基座与主题；
- PPTX 是事实标准，模板必须能落成 PowerPoint 可直接打开的 `.pptx`；
- 模板本身需要可读、可 diff、可版本管理的无损载体。

## 决策

### 1. 模板使用 JSON 作为无损载体

模板文件后缀 `*.pptmtpl.json`，结构固定为：

- `name` / `description` / `author` / `aspect`（`16:9` 或 `4:3`）；
- `theme`：预设名、六个语义色（背景 / 卡片 / 强调 / 辅助 / 正文 / 次要）、
  标题与正文字体、装饰样式与设计令牌 `tokens`；
- `layouts`：启用的内置布局清单；
- `slides`：每页的布局、标题、副标题、要点、备注、可选强调色、图片路径与
  填充方式；`theme` 还可配置页脚与页码显隐。

`tokens` 收纳字号层级、间距、圆角、密度（紧凑 / 舒适 / 宽松）、装饰强度、
字体回退链与语义色，让模板在不改版式结构的前提下调整字号体系与松紧度。
模板版本当前为 4：v2 起补设计令牌，后续版本依次增补图片 / 品牌 / 页码默认值、
图文比例与多图字段；旧文件缺省回落，`version` 高于 4 时拒绝加载并提示升级 pptmake。

读取时缺失字段回落到默认值，非法颜色 / 布局 / 画幅 / 令牌抛出带字段路径的
中文错误。写入采用「临时文件 + 原子替换」，避免中断留下半截模板。

### 2. 布局与风格由内置版式引擎生成

二十四种布局（封面 / 目录 / 章节 / 要点 / 双栏 / 引用 / 数据 / 时间线 / 结尾 /
图片 / 对比矩阵 / 图表 / 联系方式及扩展版式），按封面、结构、内容、数据、图文、
结束六组呈现。

六套风格：极光蓝、素瓷青、石墨金、珊瑚暖、商务浅色、深海墨蓝；六个语义色可逐项
修改，修改后自动转为 `custom`。四种装饰：光斑、网格、边框、极简。

版式引擎输出与后端无关的图元（矩形 / 椭圆 / 直线 / 图片 / 文本框 / 表格 / 图表），
设计坐标固定为 96 单位 / 英寸（16:9 = 1280×720，4:3 = 960×720）。Qt 画布按比例
缩放，PPTX 渲染按 `值 / 96` 换算英寸，因此预览与导出结果同源，不会各写一套版式。
图片版式支持全出血 / 40-60 / 50-50 / 双格 / 三格五种比例预设与 0.2–0.8 数值微调，
多图按栅格顺序逐格填充。

版式的字号层级、间距、圆角与装饰强度统一取自 `theme.tokens`：标题 40、正文
20 单位（15pt）、注释 13 单位，密度（紧凑 / 舒适 / 宽松）只缩放间距而不改变
结构，装饰强度只调节装饰图元与底色的混合比例。

### 3. PPTX 通过可选依赖 python-pptx 渲染

`pyproject.toml` 新增可选依赖组 `ppt = ["python-pptx>=1.0"]`，并纳入 `full` 与
`office`。模块内部延迟导入，未安装时给出「安装 `fcmd[ppt]`」的明确提示，不影响
`pptmake presets` / `init` / `inspect` 等无需渲染的子命令。

导出时使用空白版式逐页绘制图元，写入核心属性与演讲者备注；导入时读取
`ppt/theme/theme1.xml` 的配色与字体，并按「首段标题 + 其余要点」尽力还原为
模板页，无法识别的页面不丢失内容。导入识别同尺寸并排图并映射到双格 / 三格栅格
（4 张拆两页），多表按同表头合并或逐表拆页；组合形状递归取文本，SmartArt 按
节点顺序取文本；按源稿字号与行距中位数还原字号阶梯与正文行距，图片裁剪比例
反推焦点（靠左 / 右 / 上 / 下）；报告末尾输出文本 / 图片 / 表格 / 图表 / 备注
五类保留率，任一类低于 95% 时在末尾点名告警。

### 4. 双入口共享同一套逻辑

- `pptmake`（CLI）：`presets` / `init` / `inspect` / `export` / `import` /
  `validate` / `doctor` / `build`；
- `pptmakew`（Qt，侧边栏分页）：`设计` 页为「页面 / 布局库 | 实时预览 +
  缩略图 | 页面设置」三栏工作区，`样式` 页集中模板名称、风格 / 画幅 / 装饰 /
  密度 / 装饰强度、六个语义色、「设计令牌…」对话框（字号 / 间距 / 形状与符号 /
  颜色四页）与实时预览；与 llmw / wslmanw / filescanw 共用
  `fcmd.gui.sidebar.SidebarNav` 和窗口骨架。

两者共用 `_core.py`（模型与持久化）、`_design.py`（版式引擎）、`_pptx.py`
（渲染与导入）。窗口设置持久化到 `~/.fcmd/ui/pptmakew.json`。

## 验收

- `spike`：默认模板完整导出 24 页，PPTX 可重新导入且页数一致；
- 纯逻辑覆盖率 `_core.py` / `_design.py` 100%，包整体 ≥ 95%；
- `make flow` 通过，静态清单在干净工作区重生成；
- Windows 下 `pptmakew` 可打开、切换风格 / 画幅 / 装饰实时预览，模板与 PPTX
  导出成功。

## 落地状态

- 已落地：模板模型与校验、二十四种布局、六套风格、六色编辑、四种装饰、JSON
  导入导出、PPTX / POTX 导出、PPTX 主题 / 文字 / 多图 / 多表导入、CLI 与 Qt
  双入口、单测与覆盖率；模板 schema 与设计令牌层（`_tokens.py`，v1 文件自动
  迁移）；版式全面消费设计令牌；预览纯逻辑（`_preview.py`：视口适配、页面外
  遮罩裁剪、文本测量与溢出预检）；Qt 预览接入视口 / 遮罩 / 缩放 / 页面缩略图，
  文本支持斜体并按段落近似行距，溢出时在画布底部提示；Qt 窗口改为侧边栏分页
  （设计 / 样式 / 检查），密度与装饰强度在样式页调节，设计页与样式页各有一块
  实时预览画布；设计检查面板逐项列问题、跳页并支持一键机械修复；图片版式支持
  五种比例预设与数值微调；示例模板库为 8 场景（产品发布 / 季度汇报 / 方案提案 /
  融资路演 / 项目复盘 / 产品培训 / 学术汇报 / 政务汇报），每个场景声明推荐风格；
  精确预览探测 LibreOffice 并把 PPTX 转成 PDF 打开，未安装时保持画布预览；
  样式页提供设计令牌编辑对话框（字号 / 间距 / 形状与符号 / 颜色），提交前经
  `tokens_from_mapping` 统一校验并支持撤销；PPTX 导入还原字号阶梯、正文行距
  与图片裁剪焦点，五份合成样本回归保证五类保留率 ≥ 95% 且设计检查 0 问题，
  任一类低于 95% 时在报告末尾点名告警。
- 已知边界：PPTX 导入是「尽力还原」，不重建原文件的母版与占位符；多图 / 多表
  采用固定栅格与拆页映射，复杂表格与图表样式不还原；4 张以上同尺寸图片按三张
  一页切分，单页超量文本按版式容量截断并在报告中标明；导入字号按源稿中位数
  比例缩放（标题取不超过 100pt 的最大字号），多级字号差异只做等比近似；预览按
  段落高度近似字级行距，与 PPTX 的逐行行距存在细微差异；精确预览依赖外部
  LibreOffice，不随项目安装。
- 后续可选：自定义布局编辑器、母版占位符导出、模板市场式预览墙；布局与编辑体验升级见 [0055](0055-pptmake-editing-experience.md)。
