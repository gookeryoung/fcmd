# 0017 pptmake：PPT 模板设计器

## 背景

仓库已有大量文件、文档与开发工具，但缺少「排版 -> 模板 -> 演示文稿」这条链路。
需求是新增 `pptmake` 应用，提供布局设计、风格设计与精美 UI 生成能力，用于生成
PPT 模板，并支持模板导入导出。

约束：

- 纯逻辑与 Tk 分离，纯逻辑可单测，GUI 不纳入 CI 覆盖率；
- 不引入重量级 GUI 框架，沿用 `fcmd.gui` 基座与主题；
- PPTX 是事实标准，模板必须能落成 PowerPoint 可直接打开的 `.pptx`；
- 模板本身需要可读、可 diff、可版本管理的无损载体。

## 决策

### 1. 模板使用 JSON 作为无损载体

模板文件后缀 `*.pptmtpl.json`，结构固定为：

- `name` / `description` / `author` / `aspect`（`16:9` 或 `4:3`）；
- `theme`：预设名、六个语义色（背景 / 卡片 / 强调 / 辅助 / 正文 / 次要）、
  标题与正文字体、装饰样式与设计令牌 `tokens`；
- `layouts`：启用的内置布局清单；
- `slides`：每页的布局、标题、副标题、要点、备注与可选强调色。

`tokens` 收纳字号层级、间距、圆角、密度（紧凑 / 舒适 / 宽松）、装饰强度、
字体回退链与语义色，让模板在不改版式结构的前提下调整字号体系与松紧度。
模板版本当前为 2：读取 v1 文件时自动补默认令牌并升级，`version` 高于 2 时
拒绝加载并提示升级 pptmake。

读取时缺失字段回落到默认值，非法颜色 / 布局 / 画幅 / 令牌抛出带字段路径的
中文错误。写入采用「临时文件 + 原子替换」，避免中断留下半截模板。

### 2. 布局与风格由内置版式引擎生成

十三种布局：封面、目录、章节、要点、双栏、引用、数据、时间线、结尾、图片
主视觉、对比矩阵、图表、联系方式。

四套风格：极光蓝、素瓷青、石墨金、珊瑚暖；六个语义色可逐项修改，修改后自动
转为 `custom`。四种装饰：光斑、网格、边框、极简。

版式引擎只输出与后端无关的四种图元（矩形 / 椭圆 / 直线 / 文本框），设计坐标
固定为 96 单位 / 英寸（16:9 = 1280×720，4:3 = 960×720）。Tk 预览按比例缩放，
PPTX 渲染按 `值 / 96` 换算英寸，因此预览与导出结果同源，不会各写一套版式。

版式的字号层级、间距、圆角与装饰强度统一取自 `theme.tokens`：标题 40、正文
20 单位（15pt）、注释 13 单位，密度（紧凑 / 舒适 / 宽松）只缩放间距而不改变
结构，装饰强度只调节装饰图元与底色的混合比例。

### 3. PPTX 通过可选依赖 python-pptx 渲染

`pyproject.toml` 新增可选依赖组 `ppt = ["python-pptx>=1.0"]`，并纳入 `full` 与
`office`。模块内部延迟导入，未安装时给出「安装 `fcmd[ppt]`」的明确提示，不影响
`pptmake presets` / `init` / `inspect` 等无需渲染的子命令。

导出时使用空白版式逐页绘制图元，写入核心属性与演讲者备注；导入时读取
`ppt/theme/theme1.xml` 的配色与字体，并按「首段标题 + 其余要点」尽力还原为
模板页，无法识别的页面不丢失内容。

### 4. 双入口共享同一套逻辑

- `pptmake`（CLI）：`presets` / `init` / `inspect` / `export` / `import`；
- `pptmakew`（Tk）：左侧页面与布局库、中间实时预览、右侧内容与配色编辑。

两者共用 `_core.py`（模型与持久化）、`_design.py`（版式引擎）、`_pptx.py`
（渲染与导入）。窗口设置持久化到 `~/.fcmd/ui/pptmakew.json`。

## 验收

- `spike`：默认模板完整导出 13 页，PPTX 可重新导入且页数一致；
- 纯逻辑覆盖率 `_core.py` / `_design.py` 100%，包整体 ≥ 95%；
- `make flow` 通过，静态清单在干净工作区重生成；
- Windows 下 `pptmakew` 可打开、切换风格 / 画幅 / 装饰实时预览，模板与 PPTX
  导出成功。

## 落地状态

- 已落地：模板模型与校验、十三种布局、四套风格、六色编辑、四种装饰、JSON
  导入导出、PPTX 导出、PPTX 主题 / 文字导入、CLI 与 Tk 双入口、单测与覆盖率；
  模板 schema v2 与设计令牌层（`_tokens.py`，v1 文件自动迁移）；十三种版式全面
  消费设计令牌；预览纯逻辑（`_preview.py`：视口适配、页面外遮罩裁剪、文本测量
  与溢出预检）；Tk 预览接入视口 / 遮罩 / 缩放 / 页面缩略图，文本支持斜体并按
  段落近似行距，溢出时在画布底部提示；Tk 顶部提供密度与装饰强度调节。
- 已知边界：PPTX 导入是「尽力还原」，不重建原文件的母版与占位符；复杂表格、
  图表与图片不会转换为模板内容；Tk Canvas 不支持字级行距，预览按段落高度近似，
  与 PPTX 的逐行行距存在细微差异。
- 后续可选：自定义布局编辑器、母版占位符导出、模板市场式预览墙。
