# 0055 pptmake 布局设计与编辑体验升级

- 状态：S0 / S1 已落地（S2 / S3 待办）
- 日期：2026-11-15
- 需求卡片：[0055](../requirements/0055-pptmake-editing-experience.md)

## 背景

ADR 0017 交付的 pptmake 已具备十三种布局、四套风格、令牌层、实时预览与
PPTX 双向导入导出；窗口在上一轮改成侧边栏分页（设计 / 样式），但仍是
「文本页面列表 + 底部缩略图 + 右侧长表单」的拼装式布局，编辑能力也只到
「改字段」这一层：没有撤销、没有自动保存、不能拖拽排序，图片 / 要点层级 /
页脚等演示文稿常见内容无法表达。本次在**不改纯逻辑分层与 PPTX 同源渲染**的
前提下，先收敛布局与反馈（S0），再按 S1–S3 补编辑核心、内容能力与导出生态。

## 决策

| 编号 | 决策 | 落点 |
|---|---|---|
| D1 | 保持侧边栏两页（设计 / 样式），不新增导出页；导出走页标题行主按钮 + 对话框，全屏放映用 `F5` 覆盖层 | `_pptmakew_qt.py` |
| D2 | 设计页以缩略图排序器作为唯一导航源，列表 / 网格可切换；检查器改为「内容 / 版式 / 备注」页签；布局库改为版式缩略图网格 | S1 已落地 |
| D3 | 样式页宽屏左右分栏（设置卡 | 实时预览），窄屏堆叠；预览始终在可视区域，增加「应用到全部页面 / 仅当前页」 | S0（并排）/ S3（应用范围） |
| D4 | 溢出反馈前移到缩略图与状态栏：缩略图右上角显示角标，设计页状态栏右侧显示「第 i/n 页 · k 处溢出」；导出前统一检查 | S0 |
| D5 | 编辑核心：`_history.py` 保存 `TemplateSpec` 快照（冻结 dataclass，按字段 / 时间合并），上限 100 步；dirty 标记、关闭确认、60s 草稿与崩溃恢复、最近模板 | S1 已落地 |
| D6 | 内容模型升级到 v3：`SlideSpec` 增加图片 / 要点层级 / 背景变体，新增品牌层（页脚 / 页码 / Logo）；v2 模板加载时补默认值，写回时升版 | S2 |
| D7 | 图片资产口径：模板 JSON 存相对路径 + 哈希，旁放 `*.assets/` 目录；PPTX 导出时内嵌，预览走 `QPixmap` 缓存 | S2 |

| D9 | Qt 窗口按页面拆分（壳 / 设计页 / 样式页 / 画布），纯逻辑继续留在 `_core` / `_design` / `_preview` / `_pptx`；新增逻辑模块全部可单测 | `_history.py` 已落地；窗口拆分待 S2/S3 |

## 落地状态

- S0：
  - 设计页页面动作条与预览工具条改用 `fcmd.gui.widgets.FlowLayout`，窄面板整块换行；
  - 设计页三栏与样式页左右分栏尺寸写入 `PptmakeSettings.design_splitter` /
    `style_splitter`，启动时经 `parse_sizes` 容错恢复；
  - 样式页改成左侧设置卡 + 右侧实时预览的 `QSplitter`，预览不再被表单挤到折叠线以下；
  - 缩略图右上角绘制溢出角标（数量来自 `_preview.overflow_issues`），设计页状态栏
    右侧显示「第 i/n 页 · k 处溢出」；角标与状态栏同一数据源，避免两套口径；
  - 测试覆盖分栏设置解析 / roundtrip、样式页并排、初始状态栏与溢出计数。
- S1：
  - 新增 `_history.py`：冻结模板快照 + 100 步上限 + 0.8s 同字段合并；
  - 窗口接入撤销 / 重做（`Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`）、dirty 标题星号与
    关闭前「保存模板 / 不保存 / 取消」确认；
  - 60s 自动草稿（`ui/pptmakew-draft.pptmtpl.json`）与启动恢复提示，成功恢复 /
    保存后清理草稿；
  - 「文件 → 最近模板」记录最近 8 个模板，文件失效时自动移除；
  - 页面排序器合并原「页面列表 + 底部缩略图」：缩略图网格 / 紧凑列表一键切换，
    支持拖拽排序、Ctrl / Shift 多选删除 / 复制；
  - 检查器拆成「内容 / 版式 / 备注」三页，版式页显示当前布局与内容格式提示；
    标题行新增检查器收起 / 展开按钮，并把可见状态写入设置；
  - 布局库改为版式缩略图网格，风格 / 画幅 / 装饰变化时重绘。
- 已知边界：S1 的响应式只到「检查器可收起 + FlowLayout」，未做按窗口宽度自动
  折叠侧边栏的断点；内容模型 v3（图片 / 要点层级 / 品牌层）仍在 S2。

## 交接

- S0 的溢出角标与状态栏都走 `_slide_overflow_count()`；后续新增图元（图片 / 表格）
  必须保证 `build_draw_list` 同步产出，否则角标会漏报。
- 分栏尺寸字段为 `design_splitter` / `style_splitter`（`tuple[int, ...]`），
  写设置时用 `splitter_sizes()`，读取时用 `parse_sizes()`；新增分栏沿用同一口径。
- 样式页预览与设计页预览都注册在 `self._canvases`，任何模板变更调用
  `_refresh_canvases()` 一次刷新两处，不要只更新单块画布。
- 撤销 / 重做统一走 `_commit(template, label, coalesce_key=...)`：窗口里的
  `self._template` 只能由 `_commit`、`_restore_template`、`_set_template` 改写，
  不要在业务方法里直接赋值，否则历史与 dirty 状态会脱节。
- 文本输入 / 滑杆用 `coalesce_key`（`name` / `form` / `intensity`）合并连续动作；
  新增长文本编辑沿用同一模式，不要每敲一个字压一条历史。
- 自动草稿路径由设置文件目录推导，恢复成功后必须清理草稿；新增设置字段时同步
  `settings_from_mapping` / `settings_to_mapping` 与 `tests/apps/pptmake/test_pptmakew.py`。
- S2 改 schema 前先补迁移测试：v2 → v3 加载、缺省字段回落、写回版本号。
- 非目标：自由形状编辑、动画 / 转场、协作编辑、完整 PowerPoint 兼容。
