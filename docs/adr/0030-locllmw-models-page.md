# 0030 locllmw 模型页：整合 llmdownw

- 状态：已落地
- 日期：2026-11-14
- 相关文档：[ADR 0016](0016-llmdown-model-browser.md)、[ADR 0025](0025-sidebar-page-navigation.md)、[ADR 0027](0027-locllmw-rename.md)

## 背景

`llmdownw` 是独立的 ModelScope 模型浏览器 / 下载器，已有完整的搜索、类别 /
系列筛选、详情、文件清单、下载队列与本地模型管理。但 `locllmw` 的「模型」页
只能列出本地 GGUF 供启动，用户仍需切到另一个窗口去搜索、下载与管理模型目录。
两边都围绕 `llmenv` 的模型目录工作，却维护两套窗口设置与两套服务状态展示。

## 决策

### 1. 四个子页取代独立窗口

模型页改为嵌套 Notebook 承载四个同级子页，顺序固定为
浏览 → 已安装 → 转换 → 量化，启动默认停在「浏览」：

| 子页 | 内容 |
|---|---|
| **浏览** | ModelScope 在线浏览，顶部按「适合本机 / 全部 / 对话 / 编程 / 看图 / 推理 / 视频 / 音频」筛选 + 服务端排序；结果为自定义列表行（仓库名 + 系列/任务 + 下载/体积），行展开后就地显示详细信息 |
| **已安装** | 扫描模型目录下 `<组织>/<模型>` 或单级 `<模型>` 布局，打开目录、二次确认后删除；读取失败显式提示，不静默显示空列表 |
| **转换** | 只做 HF safetensors → GGUF：源目录、输出 GGUF、精度、解释器、源码、引擎 tag、预览 / 开始、进度与日志 |
| **量化** | 完整承载 GGUF 量化：输入模型、量化类型、输出目录、覆盖策略、量化器环境、进度与日志 |

子页顺序与默认子页索引由 `_locllmw_models.MODEL_TAB_NAMES` / `DEFAULT_MODEL_TAB`
统一定义，控件创建与测试都从这两个常量派生，不再散落索引常量。

浏览页不再提供关键字搜索、类别 / 系列下拉，只保留一组筛选按钮：
适合本机、全部、对话、编程、看图、推理、视频、音频。分类筛选把对应关键字交给
ModelScope 搜索（如 coder / vision / reasoning），「适合本机」按硬件快照与系统
内存估算可承载容量，在当前页按整仓体积过滤；排序仍由「排序」下拉控制。

浏览页的结果列表与概览「智能推荐」同构：每行是一张自定义卡片，只保留仓库名、
系列 / 任务与下载 / 体积三项关键内容；不再用五列表格。点击行内「展开」或双击行，
详细信息直接在行下方就地展开（同一时间只展开一行），列表保留整页宽度；
浏览页不展示 README 与文件清单，保持展开内容紧凑。筛选条与结果列表不再各包一层
Card，只保留结果行的卡片边框；QTabWidget 内容区改为无边透明，卡片内表格也去掉
自带边框，避免「面板外再套线框」的双层边框。

嵌套 Notebook 只用于页面内部的子视图，主页面导航仍是 [ADR 0025](0025-sidebar-page-navigation.md)
的 `SidebarNav`；这与「嵌套子页保留 Notebook」的边界一致。

### 2. GGUF 启动列表移到「运行」页

模型页的职责收敛为「获取与管理模型文件」，原先占用模型页的本地 GGUF 列表
（能力标签、显存适配、服务名联动）移到「运行」页顶部，与启动参数、操作栏
组成完整的「选模型 → 调参 → 启动」链路。这样模型页四个子页与用户要求一一对应，
不再把「可启动模型」和「已下载目录」混在同一棵树里。

### 3. 页面类独立，避免与宿主状态冲突

- 新增 `_locllmw_models.py` 的 `_ModelBrowserPage`，持有自己的控件、队列、
  后台任务与轮询；`locllmw` 只负责创建它并调用 `settings_dict()` / `close()`。
- 下载设置从 `~/.fcmd/ui/llmdownw.json` 迁入 `locllmw.json` 的 `download` 字段
  （`source / workers / verify / include / exclude`），非法值逐项回退默认；
  独立「下载」子页已移除，参数改由设置页维护。模型目录统一由
  `_llmconfig.models_dir` 提供，下载直接落盘，不保存第二份目录来源。
- 浏览列表每个结果行提供「下载」按钮，点击后按当前下载设置拉取该仓库；
  进度条固定在列表底部右侧，同一时间只允许一个下载。关窗时若仍在下载，
  先弹二次确认；确认后置停止事件，已下载部分保留 `.part`。

### 4. 移除独立工具 `llmdownw`

- 删除 `src/fcmd/apps/locllm/llmdownw.py`；
- 删除 `pyproject.toml` 入口、`_schema` GUI 工具集合与静态清单条目；
- 测试文件改为 `test_locllmw_models.py`，保留纯逻辑（格式化 / 过滤 / 排序 /
  增量同步 / 打开路径）并覆盖设置字典与「工具已移除」断言；
- README 工具表移除 `llmdownw`，说明并入 `locllmw`。

### 5. 转换与量化并入模型页（同级子页）

- 删除独立的转换 / 量化窗口、`pyproject.toml` 入口、`_schema` GUI 工具集合与静态
  清单条目，GUI 入口统一为 `locllmw` 的「模型 → 转换 / 量化」。
- 两块是同级子页而不是内嵌标签：转换页只保留源目录 / 输出 GGUF / 精度 / 解释器 /
  源码 / 引擎 tag；量化页承载输入模型、量化类型、输出目录、覆盖策略、量化器环境、
  进度与日志，转换页不再出现任何量化类型或量化参数控件，也没有空的量化页签。
- 两块都调用 `llmconvert` / `llmqnt` 的核心函数，默认输出统一落在
  `<models_dir>/converted/`（转换按 `<源目录名>/` 再分层），不在 GUI 重写命令。

## 验证

- 真实 Qt 冒烟：`locllmw` 打开后模型页显示四个子页，顺序为浏览 / 已安装 / 转换 /
  量化且默认停在「浏览」；浏览页加载 ModelScope 列表（自定义行），展开行后就地
  显示详情元数据，行内「下载」按钮在底部右侧更新进度；设置页可保存下载参数，
  已安装页扫描本地目录且选中与滚动正常。
- 转换 / 量化真实跑通：从模型目录选择 HF safetensors 完成一次转换，产物落
  `<models_dir>/converted/<源目录名>/`；再在量化页对转换产物执行一次量化，
  产物落 `<models_dir>/converted/`，进度与日志正常。
- 全量测试与 `make check-fast` 通过。

## 交接

- 「浏览」与「已安装」的联动（双击已安装模型回到浏览详情）已保留；如需从
  「已安装」直接启动 GGUF，应跳到「运行」页并复用模型选择逻辑，不在模型页
  复制启动按钮。
- 下载设置由设置页保存到 `locllmw.json` 的 `download` 字段；浏览页每次点击下载时
  读取最新参数，不再恢复独立下载页。
