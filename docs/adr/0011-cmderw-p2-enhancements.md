# 0011 cmderw P2 增强：搜索过滤、卷栏、属性、预览与队列调度

- 状态：生效（N3–N7）
- 日期：2026-11-11
- 关联：0005（cmderw 与 Total Commander 对齐）、0010（用户命令）

## 背景

0005 的 A–K/M 批次收尾后，cmderw 在日常文件管理上仍有几处与 TC 不对齐：
搜索只能按名称 / 内容命中、不能按大小与时间收窄；切换磁盘要手输路径；批量改
时间戳与 Windows 只读 / 隐藏属性缺失；快速查看不能切编码、不能缩放图片；传输
队列只能逐项取消，无法暂停或限制并发。本 ADR 固化 N3–N7 的口径。

## 决策

### N3 搜索过滤与结果面板

- 大小写三态：文件名搜索 `case_sensitive=None` 保持平台默认（`fnmatch`），
  `True` 用 `fnmatchcase`，`False` 对两侧 casefold；内容搜索 `None` / `True` 均
  区分大小写，`False` 加 `re.IGNORECASE`。默认值不改变既有 CLI / DSL 语义。
- 整词匹配只作用于内容搜索：把模式包装为 `\b(?:pattern)\b`，与大小写开关可叠加。
- 大小过滤接受 `1024`、`10K`、`2M`、`1.5G`、`512MiB` 等写法（1024 进制，非法抛
  `ValueError`）；时间过滤接受 `YYYY-MM-DD`、`YYYY-MM-DD HH:MM`、
  `YYYY-MM-DD HH:MM:SS`，日期按当天开始、结束日按当天 23:59:59 由 UI 传入。
  上下界均为闭区间，最小大小大于最大大小时 UI 拒绝搜索。
- 结果面板是临时窗口：列为名称 / 大小 / 修改时间 / 路径，点表头切换升降序；
  操作复用现有「打开所在目录、复制、移动、删除到回收站、加入面板选择」，不新写
  文件操作实现。排序与过滤纯逻辑在 `_search.py`。

### N4 驱动器 / 卷栏

- Windows 用 `GetLogicalDrives` 位图枚举盘符；Linux 解析 `/proc/mounts`，跳过
  proc / sysfs / tmpfs / overlay / squashfs 等伪文件系统与重复挂载点，还原
  `\040` / `\011` / `\012` / `\134` 转义；保留 drvfs 等真实挂载。
- 容量统一走 `shutil.disk_usage`，读取失败的挂载点直接丢弃，不显示 0 容量条目。
- 路径栏右侧「卷」下拉在每次打开前实时刷新，显示「挂载点 — 剩余可用 / 总容量」，
  选中即把当前面板切到该挂载点；纯逻辑在 `_volumes.py`。

### N5 批量时间戳与属性

- 对话框留空表示该项保持不变；时间格式与 N3 相同，非法输入只提示不执行。
- 「现在」填入当前时间，「清空」恢复留空；修改时间与访问时间可只改一个，
  另一个保留原值（先 `stat` 再 `os.utime`）。
- 只读 / 隐藏仅在 Windows 显示：只读走 `os.chmod` 的写权限位，隐藏走
  `GetFileAttributesW` / `SetFileAttributesW` 并保留其他属性位。
- 逐项执行、逐项收集失败；部分成功照常保留，状态栏与错误框给出成功 / 失败数量
  与前 5 个失败文件名。纯逻辑在 `_attrs.py`。

### N6 预览增强

- 编码自动探测顺序：UTF-8 BOM → UTF-16 BOM → UTF-8 严格解码 → GB18030 →
  回退 Latin-1；手动下拉可覆盖为 utf-8 / utf-8-sig / gb18030 / utf-16 / latin-1。
- 带 UTF-8 / UTF-16 BOM 的文本即使含 NUL 也按文本解码，不再误判为二进制；
  未命中 BOM 的二进制仍默认十六进制。
- 「十六进制」勾选可把任意文本强制切换为 16 字节 / 行的 offset + hex + ASCII 视图。
- 图片缩放用整数 `subsample` 倍率：默认按可视区「适应窗口」（未布局时回退
  640×480），「－ / ＋」每次翻倍 / 减半，范围 1–16，标签显示 `1:1` / `1:N`。
- 纯逻辑（探测、解码、hex、倍率）在 `_preview.py`。

### N7 队列暂停 / 恢复与并行上限

- 暂停门只拦截「尚未开始」的文件：进行中的传输继续到完成，恢复后继续取下一项；
  关窗或取消会唤醒等待线程并停止，不永久阻塞。
- 并行上限 `queue_parallel` 取 1–8，默认 1（等于原有串行行为），在队列窗口下拉
  修改并立即持久化；对下一个任务生效，不打断进行中的任务。
- 同一任务内按上限并发，进度按完成数推进；逐项状态、失败重试、取消后只清理
  「已开始未完成」项的口径不变；任务之间仍一次只跑一个（D10）。
- 暂停门与并发调度纯逻辑在 `_queue.py`。

## 交接

- 搜索的大小写默认值是三态：新增调用方不要随意把 `None` 改成 `True`，否则会
  改变 Linux 下文件名搜索的既有语义。
- 卷栏只在菜单展开时枚举，不做后台轮询；新增平台分支时保持「读不到容量即丢弃」。
- 属性对话框在非 Windows 只显示时间戳，不伪造隐藏 / 只读入口。
- 预览的编码切换只影响本次显示，不写回文件，也不改设置。
- 队列并行只作用于单个任务内部；改成任务级并发需要同时重做 `_busy` 与进度模型，
  不在本 ADR 口径内。
