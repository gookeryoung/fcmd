## 2. 已知未做项（按代码核实，不是推测）

### 2.1 编辑器（§3.8 的主要缺口）

1. **图片精细控件缺失**：`SlideSpec` 已有 `image_focus`、`image_alt`、`image_caption`、`background` 四个字段，但页面设置页只暴露「图片路径 / 填充 / 强调色」（`_pptmakew_qt.py` 布局页控件区），四字段只能改 JSON。
2. **图文比例预设缺失**：图片版式比例由版式固定，编辑器无法在 full / 40-60 / 50-50 / grid-2 / grid-3 间切换（文档 §3.8 明确列为待做）。
3. **令牌不可编辑**：样式页可改风格/画幅/装饰/密度/强度/页脚/字体/语义色，但字号阶梯、间距、圆角、描边、项目符号、图表色板、图片压暗强度均无入口（`_tokens` 已有全部读写函数）。
4. **「设计检查」面板缺失**：`validate` 的检查结果只在 CLI 输出，编辑器内没有逐项列表、跳转到问题页、导出前提示。
5. **版式库无分组与容量提示**：布局下拉是平铺列表，`_LAYOUT_HINTS` 只覆盖 5 个版式，且不显示「要点 ≤6 条」这类容量口径。

### 2.2 模板库

6. 场景只有 3 个（产品发布 / 季度汇报 / 方案提案），每个固定 9 页；没有长短版、没有行业包（融资、学术、政务、培训、复盘等）。
7. 风格只有 4 套，且都是同一套结构换色；没有「商务中性 / 浅色为主」这类更适合打印与正式场合的成品风格。
8. `presets` 不列场景清单与每场景页数，用户不知道库里有什麼。

### 2.3 导入与互操作

9. 每页只取**第一个**表格与**第一个**图表，多表/多图页只保留一张图（面积阈值 12%）。
10. 组合形状（group）、SmartArt 文本不展开；图片只支持位图，不提取裁剪信息。
11. `.potx` 已能导出，但 24 个版式的「占位符齐全性」只有整体断言，没有逐版式清单化校验（新增版式时容易漏占位符）。
12. 导入后的主题只回填 `clrScheme` 与 major/minor 字体，字号阶梯、行距不还原。

### 2.4 质量门禁

13. 对比度只有 3:1 一档：正文（<18pt）按 WCAG AA 应为 4.5:1，目前会被放行。
14. golden 只覆盖 `--flat` 路径（文本框几何）；native 路径（占位符 + 自动缩排）只有冒烟断言。
15. 没有「全矩阵」导出冒烟（4 风格 × 3 场景 × 2 画幅），新风格/新版式靠单点测试。
16. 编辑器内没有与 CLI 同源的检查计数，容易出现「CLI 拦截但编辑器没提示」。

### 2.5 明确不做（沿用上一版结论）

动画与转场、自由形状编辑、协作、像素级还原 PowerPoint 排版、21:9/16:10、VBA/宏。本路线图不改变这条边界。

## 3. 后续阶段规划

工作量档位：S（单个批次）/ M（2–3 批）/ L（4 批以上）。每个阶段独立可验收、独立提交。

### P5 编辑器设计操作面（补 §3.8 剩余项）

**目标**：让 `SlideSpec` 的所有内容字段都能在编辑器里改，并把质量检查搬到编辑器内。

范围：
- 页面设置页新增「图片焦点（5 档）/ 替代文本 / 图注 / 本页底色（inherit/dark/light/image）」四个控件；未填 alt 时控件标红提示。
- 图文比例预设：把图片版式的图区与文字区改为参数化 `image_ratio`（full / 40-60 / 50-50 / grid-2 / grid-3），编辑器用分段按钮切换，预览即时生效；导出与预览共用同一计算。
- 版式库：按「封面 / 结构 / 内容 / 数据 / 图文 / 结束」分组；每项显示 `rule_for(layout)` 的容量口径（要点 ≤N / 字数 ≤M / 标题 ≤40）。
- 「设计检查」面板：把 `_quality_issues` 从 `pptmake.py` 抽到独立模块，CLI 与 GUI 同源；面板逐项列出问题并可点击跳页；导出前若有问题，弹确认而不是静默拦截。

验收：
- 编辑器控件覆盖 `SlideSpec` 全部可编辑字段（对照字段清单逐项勾选）。
- 检查面板计数与 `fcmd pptmake validate` 完全一致（同一模板同一结果）。
- 24 个版式都有容量提示；`presets` 输出同步。
- 图片版式在 5 种比例下导出后，图区/文字区几何与预览 diff ≤1 单位。

风险：图区参数化会动到 P3 的版式几何与 11 个图片相关测试；比例预设需要新增 golden。

### P6 专业模板库扩充

**目标**：让 `init --scene` 成为「可直接交付的初稿库」，而不是演示样例。

范围：
- 场景 3 → 8：新增融资路演、项目复盘、产品培训、学术汇报、政务汇报；每个场景固定标准版，9–12 页。
- 每个场景声明式定义页序列 + 文案（现有 `SCENES`/`SCENE_TEXT` 机制），缺页时按场景自动去除而非留空页。
- 新增 2 套风格（候选：商务中性浅色、深海墨蓝），要求浅色系在投影与打印两种场景都过对比度。
- `presets` 增加「场景包」清单：场景名、页数、推荐风格。

验收：
- 8 个场景 × 2 种画幅 `init` 后 `validate` 均 0 问题、0 溢出。
- 每场景导出 golden 通过；4:3 至少每场景抽 3 页。
- 新增风格进入全矩阵冒烟（风格 × 画幅），无对比度拦截。

风险：模板库是内容型资产，评审成本高（每场景需要人工看一遍成品）；风格增加会线性抬高 golden 维护量。

### P7 导入与 potx 互操作增强

**目标**：把「导入可用」从单页单元素提升到常见商务稿的结构保留。

范围：
- 一页多图：识别 2/3/4 张同尺寸图片并映射到 grid 版式；单页多表按行数合并或拆页（明确规则）。
- 组合形状递归展开取文本；SmartArt 按节点顺序取文本。
- 导入报告升级为「保留率」：文本 / 图片 / 表格 / 图表 / 备注五类分别计数与百分比。
- `.potx` 逐版式校验：新增布局时断言 title/body/picture/table/chart/footer/sldNum 占位符齐全，缺一个即测试失败。

验收：
- 准备 5 份真实 PPTX 样本（商务、数据、图文、表格、混合），五类保留率 ≥95%，降级项在摘要中可解释。
- 24 个版式占位符校验 24/24；新增版式不写占位符会直接红。
- 导入产物 `validate` 0 问题。

风险：真实样本涉及外部文件，需要用户提供或脱敏；多图/多表的规则一旦定死，后续调整成本高。

### P8 质量门禁升级

**目标**：把「能导出」升级为「导出的每一页都达标」，并让门禁覆盖全矩阵。

范围：
- 对比度分档：正文 4.5:1、大字（≥18pt 粗体 / ≥24pt）3:1、装饰性内容豁免；同步修正当前处于 3.0–4.5 之间的 muted 文字（会略微加深）。
- native golden：导出后解析占位符与文本框几何，与 draw list 比对（阈值 1 单位），覆盖封面/章节/要点/图片/表格/图表各一页。
- 全矩阵冒烟：4 风格 × 3 场景 × 2 画幅，导出 + `validate` + 页数断言。
- 覆盖率维持 ≥95%，新增模块纳入 800 行预算。

验收：
- 全矩阵 0 拦截；分档后 `validate` 与编辑器检查面板口径一致。
- native golden 在 4 风格下均通过。
- 门禁命令保持四条不变：pytest + cov、ruff check、ruff format --check、pyrefly。

风险：4.5:1 会让部分浅灰说明文字变深，视觉层级需要重新调一遍；native golden 受 python-pptx 占位符行为影响，需要固定样本。

## 4. 建议顺序与里程碑

| 里程碑 | 内容 | 理由 |
|---|---|---|
| M1 | P5 + P8 | 都是「补检查与操作面」，改动集中在编辑器与校验，风险低、用户立刻可感知；P8 的分档会反过来约束 P6 的新风格。 |
| M2 | P6 | 在门禁收紧后扩库，避免新模板返工。 |
| M3 | P7 | 依赖真实样本与规则拍板，放最后。 |

不建议先做 P6：新增风格与场景会放大 P8 分档后的返工量。

## 5. 量化验收（自查口径）

- 编辑器：字段覆盖 100%；检查面板与 CLI 计数一致；24 版式容量提示齐全。
- 图片：5 种比例 × 2 画幅导出几何 diff ≤1 单位。
- 模板库：8 场景 × 2 画幅 `validate` 0 问题；每场景 golden 通过。
- 导入：五类保留率 ≥95%；potx 占位符 24/24。
- 门禁：pytest（含覆盖率 ≥95%）、ruff check、ruff format --check、pyrefly 全绿；全矩阵导出冒烟 0 拦截。
- 卫生：成品无「占位 / PPTMAKE」字样；封面/章节/结尾无页码（沿用 P0 口径）。

## 6. 拍板结果（2026-11-25 已确认）

| # | 议题 | 结论 |
|---|---|---|
| 1 | 图文比例预设粒度 | **预设 + 微调**：5 个预设（full / 40-60 / 50-50 / grid-2 / grid-3）+ 数值可调 |
| 2 | 风格数量 | **新增 2 套**：商务浅色、深海墨蓝（共 6 套） |
| 3 | 场景包规模 | **8 个场景，只做标准版**（不做精简版） |
| 4 | 正文对比度 | **升到 4.5:1**（大字仍 3:1，装饰豁免） |
| 5 | 设计检查面板 | **带一键修复**（截断要点 / 建议换版式） |
| 6 | 4:3 维护深度 | **进 golden 全量**（24 版式） |
| 7 | 导入多图/多表映射 | **接受固定栅格与拆页映射** |

由此产生的连带约束：
- 画面比例参数化后，5 种比例都要有 16:9 / 4:3 的 golden；比例为「微调」时按 clamp 后的实际值出图。
- 新增 2 套风格必须一次就过 4.5:1 正文对比度，进入全矩阵冒烟。
- 8 个场景每个都要有 16:9 / 4:3 的 `validate` 与 golden 结果。
- 一键修复必须有「只改结构不改文案」的边界：截断要点、建议换版式、补 alt 占位，不自动改写句子。
