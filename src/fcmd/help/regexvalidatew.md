# regexvalidatew 正则校验帮助

regexvalidatew 用 Python `re` 的 `search` 语义实时校验正则：输入模式与测试文本后，右侧结果区展示匹配数量、位置、捕获组、全匹配与 `findall` 结果；三个标志位切换后立即重新校验。历史记录在输入停止 1 秒后写入，避免每次按键都落盘。

本文对应 GUI 窗口；命令行用法见 `fcmd regexvalidate --help`，设计与边界见 [ADR 0003](../../../docs/adr/0003-package-layout.md)。

## 快速开始

1. 在「模式」输入正则，或在「示例」下拉框选择内置样例。
2. 在「测试文本」输入待匹配内容；结果区实时刷新。
3. 用「忽略大小写」「多行」「DOTALL」三个开关调整语义，无需重新输入。
4. 需要复用时从「历史」下拉框恢复最近一次输入。

校验采用搜索语义（`search`）：文本中任一处匹配即视为匹配；「全匹配」要求整段文本完全匹配。

## 常用元字符

| 写法 | 含义 |
|---|---|
| `.` | 任意字符（默认不含换行） |
| `\d` / `\D` | 数字 / 非数字 |
| `\w` / `\W` | 单词字符 / 非单词字符 |
| `\s` / `\S` | 空白 / 非空白 |
| `^` / `$` | 行首 / 行尾 |
| `[...]` | 字符集合，`[^...]` 取反 |
| `\|` | 或 |
| `*` `+` `?` | 零次或多次 / 一次或多次 / 零次或一次 |
| `{n}` `{n,m}` | 恰好 n 次 / n 到 m 次 |
| `*?` `+?` `??` | 非贪婪版本 |

## 分组与标志

| 写法 | 含义 |
|---|---|
| `(...)` | 捕获组 |
| `(?:...)` | 非捕获组 |
| `(?P<name>...)` | 命名组 |
| `(?P=name)` | 按名称反向引用 |

| 标志 | 等价写法 | 作用 |
|---|---|---|
| 忽略大小写 | `re.IGNORECASE` | `A` 与 `a` 视为相同 |
| 多行（`^/$`） | `re.MULTILINE` | `^` / `$` 匹配每一行的行首 / 行尾 |
| DOTALL（`.` 匹配换行） | `re.DOTALL` | `.` 可以跨行匹配 |

## 结果区怎么读

- **匹配数量**：`search` 命中的位置数（首个匹配 + `finditer` 后续匹配）。
- **位置**：`start-end` 字符下标，从 0 开始。
- **捕获组**：每个命名 / 编号分组的内容；未参与匹配的组显示为空。
- **全匹配**：`fullmatch` 是否成功，用于确认整段文本都符合模式。
- **findall**：所有匹配的平铺结果；有捕获组时按组返回。

## 常见问题

- **提示「正则无效」**：结果区会给出 `re.error` 的原因与位置；先缩小到最小可复现模式。
- **只匹配到第一处**：结果区始终展示全部匹配；若只看第一处，检查是否误读了「匹配数量」。
- **`^` / `$` 不生效**：多行文本需要打开「多行」标志。
- **`.` 不匹配换行**：默认行为如此；需要跨行时打开「DOTALL」。
- **想保存常用模式**：历史记录自动持久化到 `~/.fcmd/ui/regexvalidate.json`；常用组合可先写进测试文本再保存。
